* 编码与候选

  - 4 码上限；~;~ 和 ~'~ 也是码元（分别用于快符、重复上屏）
  - 满 4 码后继续敲字母 → 自动清屏重来（~auto_clear: max_length~）
  - ~;~ 引导的编码：候选唯一时自动上屏（~auto_select_pattern~）
  - 不开用户词典（~enable_user_dict: false~）→ 不学词、不自动调频，候选顺序永远稳定
  - 不喜欢 4 码上限/自动上屏，可改 schema 的 ~speller~ 段

* 反查

** 拼音反查（主方案可用）
   ~`~ 开头打拼音，例：~`ni~ → 你 / 拟 / 尼 …，候选后面显示对应的虎码编码。
   可以换成双拼：配置文件在 ~~/Documents/虎码双拼反查配置~（自然码 / 小鹤 / 微软），
   把对应目录里的 ~PY_c.custom.yaml~ 复制回本目录即可。

** 笔画反查（PY_c 方案里）
   ~`~ 开头，用 ~h s p n z~ 代表 横 竖 撇 捺 折，末位可加 ~'~ 收尾。

* 内置小工具

** 计算器（主方案 + PY_c）
   ~=~ 开头，例如 ~=1+2~ → 候选 ~1+2=3~。
   边打边算（贪婪求值），支持 ~#~ 当空格、~$~ 链式调用、以及简易 lambda 语法糖，
   细节见 [[file:lua/calculator_translator.lua][lua/calculator_translator.lua]]。

** 数字转中文
   ~S~ 加数字，例如 ~S123~ → ~壹佰贰拾叁~ / ~一百二十三~（两种写法各一条候选）；
   带小数会给到 角 / 分 / 厘 / 毫。

** 日期时间
   | 触发                    | 结果                                       |
   |-------------------------+--------------------------------------------|
   | ~/date~                 | 今天日期，多种格式（2026.10.26、2026年10月26日、Oct 26, 2026…） |
   | ~/cdate~                | 农历日期 + 节气 + 时辰                     |
   | ~/time~                 | 当前时间，多种格式（24h、12h、带秒、中文） |
   | ~/week~                 | 星期几（中/英）+ 第几周                    |
   | ~/fjq~                  | 最近的节气                                 |
   | ~N20261026~             | 查指定公历日期的农历                       |
   | ~/djs~                  | 距下次生日还有多少天（生日写死在 lua 里）  |

   同一组功能有多个别名，例如 ~/frq~、~/fnl~、~/fsj~、~/fxq~、~/lzvq~，效果相同。
   实现见 [[file:lua/shijian2.lua][lua/shijian2.lua]]；~/djs~ 里的生日（1998-08-14）可以自己改。

** 临时英文
   ~'~ 开头打英文，用 15 MB 的英文词库，带补全（~'hello~ → hello / hellos / hellow）。
   注意 ~'~ 同时是「三选」和「重复上屏」的触发键，同一个键身兼数职。

* 标点符号

  ~punctuator~ 用自定义的 [[file:symbols.yaml][symbols.yaml]]（全角 / 半角两套，共 32 个键）。
  修改候选顺序或增删符号改这个文件即可，不用动 schema。

* 用户词与学习

  - 主方案 ~enable_user_dict: false~ → 不学习新词，不记录词频
  - ~PY_c~ 例外：~encode_commit_history: true~，会把上屏内容自动造词
  - ~easy_english~ 有独立的 ~easy_english.userdb~（英文用户词）

* 维护备忘

  - 改完任何配置文件都要**重新部署**：托盘 → 中州韵 → 重新部署，或 ~fcitx5 -r~
  - [[file:user.yaml][user.yaml]] 会记住上次用的方案（~previously_selected_schema~），它优先于
    ~schema_list~ 的顺序；想换默认方案，用 Ctrl+` 选一次即可
  - ~build/~ 是部署产物，删掉会自动重建
  - 词库的 ~import_tables~ 只向下展开一层：~tigress.extended~ 必须自己列出
    ~tigress_ci~ / ~tigress_simp_ci~，漏了会丢词
  - Shift 的行为在 fcitx5 的全局热键里（~Shift+Shift_L~ 为切换输入法），Rime 侧是 ~noop~
