下载安装 ​

  1. 下载 Windows 版。同一个安装包适用于普通电脑（Intel / AMD）和 ARM 电脑，需要 Windows 10 或以上。
  2. 打开下载的压缩包，双击里面的 BigBearVPN-...-windows-setup.exe（不解压直接双击也可以），按提示允许它对设备进行更改。若提示「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」。若提示「你尝试安装的应用不是经过 Microsoft 验证的应用」，见常见问题 Q9。
  3. 按安装向导点「下一步」完成安装。默认装在 C:\Program Files\BigBearVPN，装完会自动打开，开始菜单和桌面也会有 BigBearVPN 的图标。

装过旧版的说明：

  • 旧版安装版（1.1.x）会在安装时自动卸载，不用手动处理。
  • 旧版免安装版（bigbear_win 压缩包解压出来的文件夹）用不到了，退出它之后直接删掉那个文件夹即可。
  • 新版需要重新登录一次。
  • 怎么认出旧版：版本号低于 6.0（安装版是 1.1.x，免安装版是 1.2.x）。比如免安装版首页是「连接VPN」「断开VPN」按钮，可以选「虚拟网卡模式」「系统代理模式」，设置里有「本地代理端口」。新版是节点列表左边的圆形电源按钮，左侧栏有「在线客服」。
  • 在 Cursor、Git 等软件里填过旧版代理端口的，见常见问题 Q6。

连接 VPN ​

  1. 用大熊会员账号登录。
  2. 在右边的节点列表里选一个节点。
  3. 选择「智能模式」（国内网站直连，推荐）或「全局模式」（所有网站都经过节点）。
  4. 点节点列表左边那个圆形的电源按钮，变成绿色的「已连接」就可以上网了。只选中节点不会连接。

新版只有虚拟网卡一种连接方式，电脑上所有软件都会走 VPN，连接时不用再授权。

托盘图标 ​

  • 点窗口右上角的关闭按钮只是把窗口收起来，VPN 不会断开。BigBearVPN 会留在任务栏右下角的托盘里：彩色图标表示已连接，灰色表示未连接。
  • 单击托盘图标打开窗口；右键可以连接、断开或「退出 BigBearVPN」，退出会先断开 VPN。
  • 托盘图标被收进「^」里时，可以把它拖到任务栏上常驻显示。

路由规则与在线客服 ​

  • 左侧「路由规则」可以添加自定义规则，让指定网站或 IP 网段直连或走代理，也能更新大陆规则，修改后断开再连生效。两种模式的区别和怎么确认生效，见常见问题「智能模式」和「全局模式」有什么区别。
  • 需要固定出口 IP、想从自己的服务器出去的，见专属出口（自备服务器），入口在「设置」里，需要 6.1.0 及以上版本。
  • 左侧「在线客服」可以直接留言，AI 先回复，需要时转人工。连接有问题时，点客服页右上角的诊断按钮，把诊断信息发给客服。

更新与卸载 ​

  • 有新版本时打开 BigBearVPN 会弹出更新提示，点「立即更新」，下载完成后允许授权即可自动安装并重新打开。
  • 卸载：在开始菜单的 BigBearVPN 文件夹里点「卸载 BigBearVPN」，或在「设置 → 应用」里卸载。登录信息会保留，重新安装后不用再登录。

常见问题 ​

Q1: 连接后没有网络怎么办？ ​

  1. 先换一个节点试试，再换一个网络（比如手机热点）对比。
  2. 关掉其他 VPN、加速器和代理软件（如 Clash、v2rayN、游戏加速器），它们会和 BigBearVPN 抢网络。
  3. 360、火绒、腾讯电脑管家等安全软件可能拦截 BigBearVPN，请把它加入信任（见 Q7），或暂时退出这些软件后重新连接。
  4. 仍然不行时，在「在线客服」里发送诊断信息。

Q2: 提示「VPN 组件缺失，可能被安全软件删除了，请重新安装」怎么办？ ​

安全软件（也可能是 Windows 自带的 Defender）把 BigBearVPN 的 VPN 组件（bigbear-tun.exe）删掉了。请到那个软件的隔离区恢复它，并把 BigBearVPN 加入信任（见 Q7），然后重新安装。担心是不是真有病毒的，见 Q8。不知道是哪个软件删的，可以在「在线客服」里发送诊断信息，诊断里有电脑上的杀毒软件。

Q3: 提示「另一位 Windows 用户正在使用 VPN」怎么办？ ​

同一台电脑上另一个 Windows 账号的 BigBearVPN 正连着 VPN。请切换到那个账号断开，或者注销那个账号后再连接。

Q4: 人工客服要日志文件怎么办？ ​

在左侧「设置」（6.1.0 以前叫「我的」）里点「VPN 日志」，会打开日志所在的文件夹并选中 bigbear-tun.log，把它作为附件发邮件给客服即可。日志里不包含你访问过的网站。

Q5: 登录时提示证书验证失败（CERTIFICATE_VERIFY_FAILED、self signed certificate in certificate chain）怎么办？ ​

6.0.2 以前的 Windows 版在部分电脑上缺少验证服务器证书用的根证书，登录或加载节点时会报这个错，6.0.2 起已经修复。请按上面「下载安装」的步骤下载最新版安装，不用先卸载。

已经是最新版还这样提示的，说明电脑上有软件在拦截加密连接，常见的是抓包软件（如 Fiddler、Charles）、代理软件，或安全软件的「HTTPS 扫描」「网页防护」。请退出这些软件后再登录。

Q6: 原来在 Cursor、Git 等软件里填的代理端口不能用了 ​

新版只有虚拟网卡一种连接方式，没有本地代理端口：连接后电脑上所有软件都自动走 VPN，不用在软件里填代理。

以前用旧版的系统代理模式时，在 Cursor、Git、浏览器插件等软件里手动填过 127.0.0.1:32081 这类代理的，请在这些软件的代理设置里删掉（比如 Cursor 设置里搜索 http.proxy 清空），否则代理失效后这些软件会连不上网。浏览器打不开网页时，也看一下「设置 → 网络和 Internet → 代理」，「使用代理服务器」开着的就关掉。

Q7: 怎么把 BigBearVPN 加入安全软件的信任？ ​

把 BigBearVPN 的安装文件夹 C:\Program Files\BigBearVPN 加入信任（选「添加文件夹」）。安全软件已经删掉 bigbear-tun.exe 的，先到它的隔离区（或恢复区）里恢复，或者加完信任后重新安装 BigBearVPN。不同版本的菜单名称可能略有差别：

  • Windows 自带的 Defender（没装其他杀毒软件时就是它）：在开始菜单搜索打开「Windows 安全中心」→「病毒和威胁防护」→「保护历史记录」，点开写着 bigbear-tun.exe 的那一条 →「操作」→「还原」（已阻止的选「允许在设备上」）。加入信任：「病毒和威胁防护」→「病毒和威胁防护设置」下的「管理设置」→ 往下找到「排除项」→「添加或删除排除项」→「添加排除项」→「文件夹」，选 C:\Program Files\BigBearVPN。
  • 火绒 6.x：点右上角的主菜单（或右键任务栏右下角的火绒图标）→「信任区」→「添加信任」，类型选「文件夹」。被删的文件在同一个菜单的「隔离区」里，选中后点「恢复所选」。网络防护在左侧「防护中心」→「网络防护」。退出：右键托盘图标 →「退出火绒」。
  • 火绒 5.x：首页右上角的下拉菜单（或右键托盘图标）→「信任区」→「添加文件夹」；被删的文件在「隔离区」里点「恢复」。
  • 360 安全卫士：「木马查杀」→ 左下角「信任区」→「添加信任目录」；被删的文件在「木马查杀」的「恢复区」里恢复。退出：右键托盘图标 →「退出」。
  • 腾讯电脑管家：「病毒查杀」→ 左下角「信任区」→「添加文件夹」；被删的文件在同一页左下角的「隔离区」里选中后点「恢复」。
  • 金山毒霸：右上角设置中心 →「安全保护」→「信任设置」，添加文件夹；被删的文件在设置里的「恢复区」恢复。

加了信任还连不上的，先关掉安全软件的网络防护（火绒是上面的「网络防护」）或退出安全软件，再断开重连；能连上后再把网络防护打开。

Q8: 杀毒软件说 BigBearVPN 有病毒，安全吗？ ​

这是误报。BigBearVPN 的 Windows 版目前还没有数字签名，每次更新又都是新文件，杀毒软件（包括 Windows 自带的 Defender）对这类没签名、刚发布、用的人还不多的程序比较警惕；VPN 组件 bigbear-tun.exe 又要建虚拟网卡、改网络路由，更容易被当成可疑程序。

想自己确认的，可以用你电脑上的杀毒软件手动扫描一次 BigBearVPN 的安装文件夹 C:\Program Files\BigBearVPN（bigbear-tun.exe 已经被删的，先按 Q2 恢复或重新安装）。手动扫描是按病毒库逐个检查文件，结果没有风险的，说明之前只是因为程序陌生被拦。不同版本的菜单名称可能略有差别：

  • Windows 自带的 Defender：「Windows 安全中心」→「病毒和威胁防护」→「扫描选项」→ 选「自定义扫描」→「立即扫描」，选 C:\Program Files\BigBearVPN 文件夹。
  • 火绒 6.x：首页「快速查杀」右边的下拉箭头 →「自定义查杀」→ 依次展开「本地磁盘 (C:)」→「Program Files」，勾选「BigBearVPN」→「确定」。
  • 360 安全卫士：「木马查杀」→「按位置查杀」→ 依次展开「本地磁盘 (C:)」→「Program Files」，勾选「BigBearVPN」→「开始扫描」。
  • 腾讯电脑管家：首页「安全扫描」右边的下拉箭头 →「自定义扫描」，选 BigBearVPN 的安装文件夹。
  • 其他杀毒软件：找「自定义扫描」「指定位置查杀」这类入口，选 BigBearVPN 的安装文件夹；也可以在这个文件夹上点右键（Windows 11 先点「显示更多选项」），选这个杀毒软件的扫描项。

有的杀毒软件会把代理、翻墙类软件标成「风险软件」「黑客工具」，这是按软件类型归类，不是病毒。请只用官网下载的安装包，不要用别人转发的。

确认后放心使用的，按 Q7 从隔离区恢复并加入信任。仍然不放心的，可以在左侧的「在线客服」联系客服申请退款，按退款规则办理。

Q9: 安装时提示「你尝试安装的应用不是经过 Microsoft 验证的应用」怎么办？ ​

这是电脑设置了只允许安装 Microsoft Store 里的应用，安装包本身没有问题。改成允许其他来源就能安装：

  1. 点弹窗下方的「更改应用建议设置」；也可以自己打开：Windows 11 是「设置」→「应用」→「高级应用设置」→「选择获取应用的位置」，Windows 10 是「设置」→「应用」→「应用和功能」最上面的「选择获取应用的位置」。
  2. 改成「任何来源」，再重新双击安装包。装好后想改回原来的设置也可以，不影响 BigBearVPN 使用。

这个选项是灰色的、改不了，或者找不到时：

  • 电脑可能处于「S 模式」：打开「设置」→「系统」→「激活」（Windows 10 是「设置」→「更新和安全」→「激活」），看到「切换出 S 模式」的，按提示到 Microsoft Store 免费切换后即可安装。切换是单向的，之后不能再回到 S 模式。
  • 公司或学校管理的电脑，设置可能被管理员锁定，请联系管理员或换一台电脑。
