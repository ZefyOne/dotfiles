专属出口（自备服务器） ​

开启「专属出口」后，流量先经节点的专线到香港，再从你自己的海外服务器出去，网站看到的是你服务器的固定 IP。专线的速度和稳定照旧，出口 IP 由你自己掌握。

  • 适合哪些人
  • 1. 准备服务器
  • 2. 运行部署脚本
  • 3. 放行端口

适合哪些人 ​

  • 需要固定 IP 的账号：TikTok、亚马逊等跨境电商后台、广告账户等，IP 经常变容易触发风控。
  • 已经有海外服务器，或者买了静态 IP 的 SOCKS5、HTTP 代理（见已经有 SOCKS5、HTTP 代理）。

只有 BigBearVPN App 6.1.0 及以上（安卓、Windows、Mac）支持。用 Shadowrocket 的 iPhone、iPad 和 Linux 版不支持。

1. 准备服务器 ​

  • 一台在中国大陆以外、有公网 IPv4 的 Linux 服务器：Debian、Ubuntu、Amazon Linux 2023、Rocky Linux、AlmaLinux、CentOS Stream 或 Oracle Linux（8 及以上），x86_64 或 arm64 都可以。最低配置就够用。
  • 一定要用固定公网 IP，否则服务器重启后 IP 会变。各家叫法不同，例如 AWS EC2 绑定「弹性 IP」、Lightsail 绑定「静态 IP」、Google Cloud 预留「静态外部 IP」、阿里云国际版绑定「弹性公网 IP」；其他服务商一般叫「静态 IP」或「保留 IP」。
  • 地区：专线只到香港，服务器离香港越近越快。选香港、东京、新加坡延迟最低；选美国、欧洲，每次打开网页要多等一会儿（一般多 150–200 毫秒）。
  • 费用：服务器和它的出站流量按服务商的价格收费；经过我们节点的流量照常计入套餐。

2. 运行部署脚本 ​

用 SSH 登录服务器，执行：

bash
curl -fsSLO https://bigbearvpn.sodtool.com/docs/own_exit.sh
sudo bash own_exit.sh

服务器上没有 curl 时，第一行换成 wget -O own_exit.sh https://bigbearvpn.sodtool.com/docs/own_exit.sh。

脚本会安装出口服务（Shadowsocks-2022 加密）、生成密钥和随机端口、设置开机自启、放行服务器本机的防火墙，最后自检一次，输出一行 ss:// 开头的链接。这行链接就是你的出口，相当于密码，不要发给别人。

  • 再次执行 sudo bash own_exit.sh 会更新程序，密钥和端口不变，并再次显示链接。
  • sudo bash own_exit.sh --check：只检查服务、端口和防火墙，不做修改。
  • sudo bash own_exit.sh --port 端口：换一个端口（换了以后要重新放行端口、在 App 里重新填写）。
  • sudo bash own_exit.sh --uninstall：卸载。

3. 放行端口 ​

脚本只能放行服务器本机的防火墙，云服务商控制台里的防火墙要你自己放行：在安全组或防火墙规则里添加入站规则，端口填脚本给出的端口，TCP 和 UDP 都要放行，来源填 0.0.0.0/0（我们节点的 IP 不固定）。

例如 AWS EC2 在「实例 › 安全 › 安全组 › 编辑入站规则」，Lightsail 在实例的「联网 › IPv4 防火墙」，Google Cloud 在「VPC 网络 › 防火墙」。

4. 在 App 里设置 ​

  1. 先断开 VPN（已连接时不能修改）。
  2. 打开 设置（手机上点首页右上角的头像，Windows、Mac 在左侧栏；6.1.0 以前叫「我的」），在「连接」分区点 专属出口。
  3. 把脚本输出的链接粘贴到「链接」，点 识别，再点 保存。
  4. 打开 使用专属出口。
  5. 回到首页连接。连接后再进「设置」，专属出口那一行显示「出口 你服务器的 IP」就是生效了；在「专属出口」页点 测试出口 可以随时再查一次。

想关掉时，断开后关掉「使用专属出口」，再连接就恢复为从节点出去。

已经有 SOCKS5、HTTP 代理 ​

买的静态 IP 代理、或者自己搭的 SOCKS5、HTTP 代理也能用，不用运行脚本。在「专属出口」页把类型选成 SOCKS5 或 HTTP，填地址、端口、用户名和密码后保存；也可以粘贴 socks5://用户名:密码@地址:端口 这样的链接再点识别。已有的 Shadowsocks 服务器同样可以粘贴 ss:// 链接。

  • 地址要填公网 IPv4 或域名，不支持 IPv6 和局域网地址。
  • HTTP 代理不支持 UDP，语音通话、部分游戏和视频会议会用不了；SOCKS5 要服务商支持 UDP 才行。网页不受影响，浏览器会自动改用 TCP。
  • 代理服务商限制了来源 IP 的（白名单），要放行我们节点的 IP，而节点 IP 不固定，这类代理不适合。

开启后哪些流量走专属出口 ​

  • 原来经过节点的连接都改从你的服务器出去：全局模式下的大部分连接、智能模式下的海外网站、路由规则里设成「代理」的网站，这些网站的域名也由你的服务器解析。开启后在电脑或手机上查这些网站的地址，看到的是 198.18 开头的地址，这是正常的。
  • 不受影响：智能模式下的中国大陆网站、路由规则里设成「直连」的网站、局域网，以及安卓「按应用分流」里不走 VPN 的应用。
  • 路由规则里按 IP 网段设的规则，对通过域名访问的海外网站不生效（原因同 FakeIP），直接用 IP 访问的照常生效。
  • BigBearVPN 自己的服务器仍然经节点连接，出口坏了也能登录、刷新会员信息、联系在线客服。

出口连不上怎么办 ​

出口连不上时 不会退回节点：经节点的连接都会失败，VPN 仍然显示已连接，这样网站不会突然看到另一个 IP。首页会提示「专属出口连不上（节点正常）」。按顺序检查：

  1. 云控制台的安全组或防火墙规则，是否放行了脚本给出的端口，TCP 和 UDP 都要。
  2. 在服务器上执行 sudo bash own_exit.sh --check，服务没在运行就重新执行 sudo bash own_exit.sh。
  3. 服务器的 IP 有没有变：没绑固定 IP 时重启会变。变了就重新执行脚本拿到新链接，在 App 里重新识别、保存，断开再连。
  4. 还是不行，可以先断开、关掉「使用专属出口」照常使用节点，再把诊断信息发给在线客服。

如果提示的是连不上外网、节点也不通，问题不在你的服务器，换一个节点试试。
