下载安装包 ​

根据你的 Linux 系统架构下载：

  • 下载 amd64 版本
  • 下载 arm64 版本
  • 下载 OpenWrt amd64 版本
  • 下载 OpenWrt arm64 版本

普通 Linux 系统使用 bigbear-linux-* 安装包，OpenWrt 设备使用 bigbear-openwrt-* 安装包。大多数 Intel / AMD 电脑选择 amd64，ARM 服务器、树莓派或 ARM64 路由器选择 arm64。

安装到 /opt/bigbear ​

以 amd64 版本为例，进入安装包所在目录后运行：

bash
sudo mkdir -p /opt/bigbear
sudo tar -zxvf bigbear-linux-amd64.tar.gz -C /opt/bigbear
cd /opt/bigbear

如果下载的是 arm64 版本，把安装包文件名改成 bigbear-linux-arm64.tar.gz。

首次授权 ​

BigBearVPN Linux 版本使用 TUN 模式，首次使用需要授权：

bash
sudo ./bigbear install-cap --apply

登录账号 ​

bash
./bigbear login --email <邮箱>

运行后输入会员账号密码。

选择节点 ​

查看节点：

bash
./bigbear nodes

选择节点：

bash
./bigbear select <node-id>

例：选择 ID 为 1 的节点：

bash
./bigbear select 1

连接 VPN ​

bash
./bigbear start

连接后可以查看当前外网 IP：

bash
curl ifconfig.me

如果显示的 IP 已变化，说明 VPN 已连接成功。

停止 VPN ​

bash
./bigbear stop

Web 管理界面 ​

Ubuntu 桌面用户可以启动本机 Web 管理界面。

前台启动 Web UI：

bash
./bigbear web

然后在本机浏览器打开：

text
http://127.0.0.1:32080

Web UI 支持登录、加载和选择节点、切换 Rule / Global、启动/停止 VPN、查看状态和最近日志。

如果希望 Web UI 在后台运行：

bash
./bigbear web start
./bigbear web status
./bigbear web stop
./bigbear web restart

如果端口被占用，可以换一个本机端口：

bash
./bigbear web start --listen 127.0.0.1:32081

Web UI 默认只监听 127.0.0.1:32080，只允许本机访问。

如果需要在同一局域网的其他设备访问，需要显式开启 LAN 模式：

bash
./bigbear web start --lan --listen 0.0.0.0:32080

然后在同一局域网设备访问：

text
http://<服务器局域网IP>:32080

如果服务器启用了防火墙，需要放行 32080 端口。LAN 模式会把可控制 VPN 的 Web UI 暴露到局域网，请只在可信内网使用。./bigbear web start 和 ./bigbear web stop 只控制 Web UI 进程，VPN 仍通过页面按钮或 ./bigbear start / ./bigbear stop 控制。

常用命令 ​

查看帮助：

bash
./bigbear help

查看版本：

bash
./bigbear version

查看状态：

bash
./bigbear status

规则模式：

bash
./bigbear route-mode rule

全局模式：

bash
./bigbear route-mode global

退出登录：

bash
./bigbear logout

常见问题 ​

Q1: 提示 TUN 模式需要 root 或 CAP_NET_ADMIN？ ​

重新执行授权命令：

bash
sudo ./bigbear install-cap --apply

Q2: 节点不可用怎么办？ ​

停止 VPN 后重新选择节点：

bash
./bigbear stop
./bigbear nodes
./bigbear select <node-id>
./bigbear start

Q3: 如何开启/停止 VPN？ ​

开启 VPN：

bash
./bigbear start

停止 VPN：

bash
./bigbear stop

Q4: 如何查看运行日志？ ​

VPN 日志路径：

text
~/.local/state/bigbear/sing-box.log

Web UI 后台日志路径：

text
~/.local/state/bigbear/web.log
