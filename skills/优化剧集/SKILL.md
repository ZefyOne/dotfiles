# 优化剧集

优化剧本中已写好的剧集，让台词更自然、更贴近真实对话。**牢记：这是剧本，不是小说——用对话推动情节，不要堆砌描写。**

## 触发词

- `"优化第X集"` — 单集（如"优化第45集"），文件通过 `@文件名` 指定
- `"优化第X集到第Y集"` — 范围（如"优化第45集到第48集"），文件通过 `@文件名` 指定
- `"优化X-Y集"` — 简写范围（如"优化41-45集"），文件通过 `@文件名` 指定
- `"润色第X集"` / `"润色X-Y集"` — 同上
- `"打磨第X集"` / `"打磨X-Y集"` — 同上

注意：用户通过 `@文件名` 方式指定要修改的文件，skill 不自作主张查找文件。

## 格式规范

优化后的格式与原剧本保持一致：

- 每集以 `第X集` 开头为标题行
- 第二行写 `场景：地点1/地点2`（或 `人物：角色1、角色2`）
- 正文放在**同一行**，不换行
- 对话格式：`角色名：对话内容`
- 动作/场景描述直接写在正文中
- 特殊标记保持原样：`角色VO`、`角色OS`、`【闪回】/【闪出】`、`【画面一转】`

## 核心原则：这是剧本，不是小说

**剧本的核心是对话，不是描写。** 每一集的正文应该主要由角色之间的对话构成，用对话推动情节、展现冲突、塑造人物。切忌写成小说——不要出现大段心理描写、环境渲染、外貌刻画、比喻修辞等小说化表达。

**对话要像打乒乓球，有来有回。** 不要让一个角色连续说太长的台词，角色之间要频繁交替发言，一方说几句另一方就接上，形成碰撞感。一段台词超过两个完整句子，就要考虑插入对方回应或者动作打断。

## 台词四要素

每一句台词都必须同时满足以下四个条件，缺一不可：

1. **交待信息** — 台词要让观众接收到有效信息，不能是空洞的废话。观众听完要知道发生了什么、为什么发生、将要发生什么。如果一句台词删掉后不影响观众理解剧情，那就是无效台词。
2. **符合人设** — 台词要符合说话人的身份、性格、立场和当下的处境。王海自私贪婪，他说的话就要透出自私劲儿；赵峰沉稳有城府，说话就要有分寸和底气；李婉月投机取巧，台词就要有见风使舵的味道。不能所有人说话都是一个味儿。
3. **表达情绪** — 台词要反映人物当下的情绪状态：愤怒、焦急、得意、心虚、慌张、惊喜……让观众通过台词感受到人物的内心波动。干巴巴的陈述句没有感染力，要通过语气词、重复、反问、断句等手法把情绪带出来。
4. **推进剧情** — 每一句台词都要推动剧情向前走一步。要么制造冲突、要么激化矛盾、要么揭示信息、要么推动角色做出决定。不能让剧情原地打转。

> **检查方法：写完一段对话后，逐句问自己——这句删掉，观众还能看懂吗？如果删掉不影响，那就是无效台词，必须重写或删除。**

## 优化原则

0. **只改中间，不动首尾**：每集正文的开头和结尾是剧情的起承关键，优化时不得修改。只能对正文的中间部分进行调整和扩充，确保首尾的承接和收束不受影响。
1. **内容不变**：核心情节、人物关系、关键台词不能改动。故事的走向、冲突、结局不能偏离原意
2. **台词更自然**：加入口语化的表达、情绪递进、语气词，让人物对话更贴近真实说话方式。避免干巴巴的一问一答，让对话有来有回、有交锋
3. **对话要有来有回**：不要让一个角色连续说太长的台词，要频繁切换角色交替发言。一段台词超过两句话就要考虑插入对方回应或简短动作打断。真实对话是碰撞出来的，不是一个人把话全说完再说下一个人
4. **动作精简**：动作描写点到为止，用一两个词交代清楚即可（如"皱眉"、"笑了"、"摇头"），不要堆砌大段动作描述。**严禁**使用小说式的神态、心理、环境描写
5. **每集控制在380-450字**：正文（不含标题行和场景行）要求380-450个中文字符。字数不够时通过**丰富对话内容**来扩充，超过450字则精简对话。**不要靠堆砌描写来凑字数**
6. **正文保持在同一行**：所有正文内容写在一个段落里，不手动换行

## 写作步骤

1. 根据用户指定的文件名和集号，读取对应文件内容
2. 找到指定集号的段落（以`第X集`开头，到下一个`第X集`或文件末尾结束）
3. 逐集按照优化原则进行改写：
   - **检查是否有小说化表达**（心理描写、环境渲染、外貌刻画、比喻修辞等），如有则改为对话或直接删掉
   - **检查是否有长独白**：是否有角色连续说话过长？如有则拆开，插入对方回应或动作打断
   - 重写对话，让其更自然有层次、有交锋
   - 扩充对话内容（用对话本身来推进情节），不要靠堆动作凑字数
   - 检查是否改变了原意
4. **字数验证**：将优化后的正文单独摘出，用 `wc -m` 统计字符数。不足380字则返回第3步继续扩充，超过450字则删减至该范围内，直到达标为止
5. 将最终内容写回对应的文件

## 示例

优化前：
```
第四十五集
场景：王家饭店大厅
李婉月拿着手机凑过来，递到王海：老板你看，过几天市里要搞优秀饭店评选，评上了那可是全市通报。王海看向手机，皱眉：评这东西有啥用？李婉月笑了：用处大了，全市一通报，谁不知道咱们王家饭店？王海眼睛一亮：对啊！他脸色又沉下来：可对面赵峰那家肯定也报名，万一他们选上了呢？李婉月凑上前：老板放心，咱们这条街的名额只有一个。王海搓了搓手：说得轻巧，万一选不上咋办？李婉月压低声音：评审组长姓周，我专门打听过了，这人好说话。到时候包几个红包意思意思，他还能不给面子？王海犹豫片刻：好，就这么干！
```

优化后：
```
第四十五集
场景：王家饭店大厅
李婉月拿着手机凑过来：老板你看，过几天市里要搞优秀饭店评选，评上了那可是全市通报，比打多少广告都管用。王海皱眉：评这东西有啥用？又不能当饭吃。李婉月笑了：用处大了去了！全市一通报，谁不知道咱们王家饭店？到时候客人多得数都数不过来。王海眼睛一亮：对啊！可对面赵峰那家肯定也报名，万一他们也选上了呢？李婉月笑了：老板放心，这条街的名额只有一个，咱们拿下名额，赵峰他们只能干瞪眼。王海搓了搓手：说得轻巧，评审又不是咱家的人，凭什么选咱们？李婉月压低声音：评审组长姓周，我专门打听过了，这人好说话。到时候包几个红包意思意思，他还能不给面子？王海一咬牙：好，就这么干！舍不得孩子套不着狼！
```
