# 短剧_总结简介人设

根据短剧剧本的集纲，重新总结出剧本的**简介**、**人物设定**和**每十集的剧情梗概**，写入一个新的 `标题头.org` 文件。简介在最前面，人设按戏份重要程度依次放在中间，剧情梗概放在最后。

## 触发词

- `"总结简介人设"` / `"生成简介人设"` / `"提取简介人设"`
- `"写简介和人设"` / `"总结一下人物和剧情"`
- `"生成标题.org"` / `"写标题.org"`

注意：用户通过 `@文件名` 方式指定要分析的剧本文件，skill 不自作主张查找文件。

## 输出结构（按顺序）

1. **简介** — 开头，一段话概括整部剧讲什么、大致走向
2. **人设** — 中间，按戏份重要程度从重到轻依次排列
3. **每十集剧情梗概** — 最后，按集数顺序（第1-10集、第11-20集……）逐段概括，注意，只写前三十集，后面五十集不用总结梗概

## 内容要求

- **只根据文档分析**，不要自行添加任何内容。文档里没有的人物、情节、细节一律不写。
- **足够精简**，不要多余信息。能一句话说清的不用两句。
- **忽略文档中已有的简介和人设**，重新总结出一份更精简的内容，不要照抄原文。
- 简介与梗概要清晰，让读者看完知道大概剧情。

## 人设格式

```
人物名
身份：xxx
性格：xxx
外貌：xxx
着装：第x集-第xx集，穿着普通灰短袖、运动鞋
```

- 每个人物块之间用空行隔开
- **身份**：只写人物身份，如"王家饭店老板"
- **性格**：只写性格特征，如"自私贪婪、见风使舵"
- **着装**：按集数区间写穿着，如"第1集-第20集，穿着普通灰短袖、运动鞋"；原文没有分段穿着信息时，按原文实际描述的穿着写，没有着装描述的字段就写"不详"或省略

## 写作步骤

1. 读取用户 `@` 指定的剧本文件
2. 通读全部集纲，识别剧情主线、核心矛盾、主要人物，以及各人物的戏份轻重
3. 先写简介（一段话概括整剧）
4. 再写人设：按戏份从重到轻，逐个按上面的格式写
5. 最后写每十集的剧情梗概（如第1-10集、11-20集……），每段概括该十集发生的剧情
6. 将全部内容写入**以剧本标题命名的 `.org` 新文件**（如 `双穿赶山，开局养殖小龙虾.org`；用户明确指定"标题.org"时跟随用户命名），**不动任何其他文件**
