# 扩写剧集

将剧集提纲中的要点扩写成完整的剧本格式。

## 触发词

- `"扩写第X集"` — 单集（如"扩写第三十一集"），文件通过 `@文件名` 指定
- `"扩写第X集到第Y集"` — 范围（如"扩写第1集到第10集"），文件通过 `@文件名` 指定
- `"扩写X-Y集"` — 简写范围（如"扩写31-40集"），文件通过 `@文件名` 指定
- `"写第X集"` / `"写第X集到第Y集"` — 同上
- `"把第X集写出来"` / `"把第X集到第Y集写出来"`

注意：用户通过 `@文件名` 方式指定要修改的文件，skill 不自作主张查找文件。

## 范围定位

- 单集：读取文件内容，找到该集提纲进行扩写
- 范围在同一文件内（如1-5集）：一次性处理该文件中的多集

## 格式规范

严格遵循 `result.md` 中的剧本格式：

- 每集以 `第X集` 开头
- 人物这行不用写：`人物：角色1、角色2`（列出本集出场角色这些，都不用写）
- 必写 `场景：地点1/地点2`（场景地点，用/分隔多个场景）
- 对话格式：`角色名：对话内容`
- 动作/场景描述直接写正文，精简为主
- 特殊标记：
  - `角色VO`：画外音
  - `角色OS`：内心独白
  - `【闪回】/【闪出】`：回忆场景
  - `【画面一转】`：场景切换

## 台词四要素

扩写时每一句台词都必须同时满足以下四个条件，缺一不可：

1. **交待信息** — 台词要让观众接收到有效信息，不能是空洞的废话。观众听完要知道发生了什么、为什么发生、将要发生什么。如果一句台词删掉后不影响观众理解剧情，那就是无效台词。
2. **符合人设** — 台词要符合说话人的身份、性格、立场和当下的处境。王海自私贪婪，他说的话就要透出自私劲儿；赵峰沉稳有城府，说话就要有分寸和底气；李婉月投机取巧，台词就要有见风使舵的味道。不能所有人说话都是一个味儿。
3. **表达情绪** — 台词要反映人物当下的情绪状态：愤怒、焦急、得意、心虚、慌张、惊喜……让观众通过台词感受到人物的内心波动。干巴巴的陈述句没有感染力，要通过语气词、重复、反问、断句等手法把情绪带出来。
4. **推进剧情** — 每一句台词都要推动剧情向前走一步。要么制造冲突、要么激化矛盾、要么揭示信息、要么推动角色做出决定。不能让剧情原地打转。

> **检查方法：写完一段对话后，逐句问自己——这句删掉，观众还能看懂吗？如果删掉不影响，那就是无效台词，必须重写或删除。**

## 扩写规则

**只扩写中间，不动首尾。** 每集提纲的第一条和最后一条是剧情的关键锚点，扩写时必须原样保留，不得修改或删除。只能对中间的提纲条目进行扩充。这样可以保证每集的开头承接自然、结尾收束有力，不会越写越偏。

## 写作步骤

1. 读取用户 `@` 指定的文件，根据集号找到对应的提纲段落（以`第X集`开头，到下一个`第X集`或文件末尾结束）。**注意：第一条和最后一条提纲要点保持原样，只扩充中间的条目**
3. 将每个提纲要点转化为完整的剧本段落
4. 多集处理时，逐集按顺序处理，每集之间用空行隔开
5. 正文内容在同一行，**不要换行**
6. 每个场景用 `场景：` 标明
7. 场景描写精简，重点在台词和动作
8. 每集约400字左右
9. **删除提纲要点**，只保留完整的正文内容（即每集以`第X集`开头，直接跟`场景：`，不再保留下方的`- `提纲条目）
10. 将扩写后的内容写回对应的文件

## 示例

提纲（原文）：
```
第三十一集
- 写他们装修的过程，说真气派啊
- 然后赵峰出来看到这边情况，说两句
- 最后王海看到赵峰，得意放话
```

扩写后（提纲已删除）：
```
第三十一集
场景：王家饭店大厅
工人进进出出搬着旧桌椅，几个人踩着梯子挂水晶灯。王海站在大厅中间，仰头看着，满脸得意。李婉月走过来：老板，水晶灯挂好了。王海抬头望去，灯光一照满屋通亮，又看看新地砖和新桌椅，大喜：气派！真他娘的气派！这才是我王海该有的排场！...
