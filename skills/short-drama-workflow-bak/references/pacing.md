# 节奏标准

## 新剧先确认节奏方向

用户确认[样稿拆解](source-adaptation.md)、提供设定并明确这部剧的金手指爽点后，按[长线标准](long-arc.md)先确认采用双线还是三线，构思各线怎样互相推进，再查 `assets/各种题材节奏/<题材名>.md` 分配集数。用户本轮明确指定的集数和安排优先，其余集数按同题材文件实际覆盖的范围排，仍有空缺才用通用节奏补齐。题材文件规定集段、顺序和明确标出的推进节点，具体桥段和示例台词按本剧需要调整。在对话里注明本剧采用几条线及各线是什么，再发节奏依据和[剧情循环](plot-cycle.md)，只确认未定的排法。跨阶段依据[四阶段流程](../SKILL.md)采用对应的正文版本，从实际末场接上。

## 在分集前确认篇幅

按各线已经想清的因果，把本剧循环列成可确认的排法。标出开局、该批各轮的环节顺序、每个环节占几集，以及哪几个环节合用一集。用整集或上、下半集表示占用，按戏的功能分段。每段写清要推进哪条线、要留给后面什么条件。对有意拉长或压缩的环节，说明新增了哪一个值得演的动作、选择或兑现。多集[打脸](face-slapping.md)按本剧已定的高潮集亮出主角优势，未指定时放在该段倒数第二集末，卡在反派的震惊台词。高潮后留约一集接原现场，演反派的反应、实际代价和离场。

新剧从第1集起写时，先列第1–10集的节奏，另用一句话写跨批事件怎么接。用默认节奏时，写第11集如何接住第10集、收完这场打脸。节奏表写每集的作用与篇幅，并给出常规轮次中「主角收获赚钱」和「打脸反派」的参考篇幅。确定参考篇幅时同步粗排全剧各轮的起止集数，确认能在第80集收束。集数和作用已有明确安排的部分直接沿用。

第1–10集和第11–30集分别在对话里交逐集剧情和卡点，涉及待定的篇幅时一并确认。依据用户确认的第1–30集正文，为第31–80集交一次分段大纲，按连续集段说明主要事件、结果和接法。两种规划都按[模板](templates.md)给每段人物交往附一次双方的态度和打算。大纲确认后，第31–50集和第51–80集依次在内部细排每集的作用、篇幅和卡点。四批都按集段任务从[已确认的样稿拆解](source-adaptation.md)选桥段。

单独接写第51–80集时，从用户指定的前五十集正文接续。按[分段大纲模板](templates.md#后五十集分段大纲)提交本次第51–80集的大纲，确认后细排。

## 前十集默认节奏

按本剧已定节奏和同题材节奏文件排集，下表只补两者未覆盖的部分。按[素材改编](source-adaptation.md)从拆解记录选取符合本剧人物、收获和冲突的桥段。适合售卖的题材按售卖兑现，不含交易的题材用本剧可见的成果承担同样的作用，例如神医题材当场治好第一位病人。采用默认走法时，先立住第1集的伤害，再倒查第8–11集怎样把这件事翻回来。

| 集数 | 剧情任务 |
|---|---|
| 第1集 | 先让观众替主角生气。用一两件分量足的付出，交代主角曾怎样不遗余力地帮对方、当时不求回报。让忘恩负义或背叛主角的人当面把这份好当作应得的，再演主角受了什么委屈。末尾演出金手指觉醒，给观众一个具体的翻盘期待。主角在集尾首次认出有分量的值钱物品时可用震惊卡点，其余按[集尾卡点](hooks.md)选择与觉醒结果相连的收法。 |
| 第2集 | 主角试用金手指，拿到第一次具体收获。 |
| 第3集 | 主角兑现第一次收获，例如卖货赚到第一笔钱，或交出本题材可当场验证的成果。 |
| 第4–5集 | 完成第一段打脸。第4集末亮优势，卡在反派的震惊台词。第5集接现场写反应、代价和离场。可沿用首集反派，也可引入和首集冲突无关的新反派。新反派可作为长期对手留到后续。 |
| 第6–7集 | 主角再用金手指拿到新收获，为下一次变现或兑现成果准备筹码。 |
| 第8–9集 | 开始第二段打脸，让第1集欺负主角的反派回场。把售卖或本题材的成果兑现放进冲突。反派围绕当初的羞辱、针对主角这一轮的优势继续打压，让观众替主角生气，期待他当场亮出优势。 |
| 第10集 | 末尾当场亮出主角的优势，证据要足以推翻首集反派对主角的判断。首集反派亲眼见证后说出最后一句震惊台词，说完收集。 |
| 第11集 | 直接接第10集现场。一次性小反派从震惊转为狼狈求饶，长期反派嘴上仍不服。演出反派怎样付出肉痛的实际代价、主角拿到什么和反派如何离场，再由这场打脸的结果引出下一事件。 |

## 后续阶段按剧情调整篇幅

先按用户已定的安排和题材节奏文件排后续各轮。仍需补齐时，以第1–10集的常规篇幅为参考，后续按第11–30、31–50、51–80集三个阶段排。每个阶段新开一轮时，可以让「主角收获赚钱」和「打脸反派」分别比上一阶段多写约2集，具体看各自有多少值得演的进展。发现、验证和成交计入收获赚钱，找事、反击和付代价计入打脸。

- 已开始的轮次跨批时，沿用已确认的篇幅把这轮写完，下一轮再按当时的剧情和阶段排。默认第11集先接第10集的原现场，演完这轮打脸的反应、代价和离场。用户确认了其他高潮或收尾集数时，照本剧的安排承接。
- 随剧情进展核对后续轮次和第80集的收束位置。通常在第51–80集临近大结局时，按剧情连贯性加快或放慢。例如原拟七八集的打脸可压成两三集，演清起因、反转和结果。第80集必须是全剧结局。第31–80集逐集细排时，按已确认的大纲落实各段。涉及改动用户已确认的集段或关键节点时，标出受影响的集数和改法。
- 每集至少有一项新的障碍、选择、成果或处境变化。拉长的打脸按[打脸剧情](face-slapping.md)分段升级。多集打脸按已定的高潮和收尾集数演出反转、反应和代价。未指定时，该段倒数第二集末亮决定胜负的优势，最后一集接原现场演反应和代价。

## 把确认的分配落实到戏里

- 先确定每集主要演哪一件事、到集尾现场发生了什么变化。半集也要办完自己承担的事，卖钱要落到成交或实际收钱，改善生活要落到人物当场得到或改变的东西。
- 一段连续剧情尽量围绕一两个主要场景推进，跨集也优先延续原现场。把等人、走路、反复试探、同一消息的多次转述压成必要动作或一句话。能当天处理的事按当天推进，跨天有可见原因和作用。
- 把篇幅给出手、见证、关键选择和人物反应。动作或反应承接上一集时，开场先处理观众在等的那件事，再切到新的冲突。多集写同一个事件时，逐集写出新增的结果或处境变化。
- 新写的完整集按1030字安排，可在1000–1060字内随剧情调整，含标点，统计口径见[分场正文模板](templates.md#分场正文)。每批收稿时把本批字数加到已完成集数的累计字数中，按剩余集数安排后续篇幅。用户指定的前十集定稿按实际字数计入，只提醒超出范围的集数，照原文接写和合并。新稿偏短时先查关键戏有没有演足，缺哪一拍就补具体行动、交锋、反应或得失。偏长时优先压缩重复交代和普通过程。调整会改变用户已确认的集数分配时，先提交调整方案请用户确定。
