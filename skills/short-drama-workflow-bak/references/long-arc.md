# 长线发展

先构思本剧的主线和支线怎样互相推进，再用[节奏表](pacing.md)排集。每轮用[剧情循环](plot-cycle.md)写完当下的小故事，让已发生的事持续影响人物、资源和后续选择。

## 确认双线或三线

拿到新剧设定后，用户未明确指定线数时，问「这部用双线，还是加一条感情线做三线？」等用户回答后再构思、排集和选材。用户已明确指定时，按其要求构思。在规划开头注明采用几条线及各线是什么。

- **双线。** 赚钱主线写主角如何用金手指获得收入、销路或合作机会，逐步扩大事业。反派线从主角刚取得的成果生长出来。写清反派从哪里得知成果、能从中夺走什么或因此失去什么、为什么偏在现在来找事。反击留下实际结果，成为主角下一步发展的条件。
- **三线。** 在赚钱主线和反派线之外加感情线。写清双方因哪件事改变态度，以及关系变化怎样影响后续选择。比如女主亲眼看到主角验准一件货，后来遇到有风险的生意，才愿意主动与他合作。

## 从终局反推阶段变化

1. 用一句话写清主角最终要做成什么，再写出第80集能拍出来的兑现。比如「陈海生让女儿有安稳的家」最终要在父女的住处、生活或选择里看得见。同步想清主要反派怎么走到终局，三线剧再确定感情线最后落实在哪个选择上。
2. 按第1–10、11–30、31–50、51–80集四个阶段构思各线的推进。每阶段写清**开头继承了什么条件、中间哪条线影响了另一条线、结尾留下什么供下一阶段使用**。沿用用户明确指定的节点，其他先确定发展方向和前置条件，随后再按节奏表分集。
3. 在本批安排能实际改变阶段状态的戏。人物认可一次行动、愿意一起做事、把重要决定交给对方，是不同变化。写清每次变化由哪个行动触发，并用后续行动证明它留下了影响。

## 让本轮的结果进入下一轮

每轮规划时填下表。用具体事件说明因果。

| 项目 | 要回答的问题 |
|---|---|
| 上轮留下的条件 | 本轮哪些人物、机会、阻力或决定来自前面已发生的事？ |
| 本轮改变的状态 | 主角拿到了什么、付出了什么？谁的信任、知情、资源或处境发生了变化？ |
| 后文会用到的结果 | 谁将利用或回应这一变化？它怎样改变下一轮的目标、找事动机、解决办法或代价？ |
| 本轮末场和下轮开场 | 本轮收尾集的末场，谁用什么动作或台词把哪个结果带进下轮？下轮开场谁因此做了什么？末轮填写结局兑现。 |
| 全剧进展 | 这轮完成了哪个阶段动作？哪个节点还需兑现，届时观众要看到什么？ |

- 每段非终局事件收完时，在它的收尾集末场演出一个具体结果，由当场人物的动作或台词引出下一事件。下一事件开场让人物因这个结果采取行动。同一轮内换事件时也照此衔接。普通卡点可直接落在由结果引出的决定或行动上。采用[震惊卡点](hooks.md)时，需要的线索可先演出来，或由符合卡点要求的末句带出。
- 让本轮至少一个结果在后文起作用，其他小冲突可以当场收干净。结果暂时回收不了时，记下预计兑现位置或触发条件。末轮的结果落实到大结局。
- 让升级体现在主角能做的事、需要承担的责任、对手还能使用的筹码、关系中的主动选择。前一次赔钱或失去门路的反派，再次回场要用还握在手里的东西，争夺眼下确实有价值的利益。
- 先用已出现的人、资源、承诺或选择推进。确有需要再引入新人物或新规则，并给观众看得见的来由。

**示例。** 第一次卖鱼赚到的钱让父女修好漏雨的屋顶。饭店采买吃过第一批鱼后上门交定金，约好连收三天，每天一百斤。隔壁鱼贩认得采买，亲眼看见定金落到主角手里，便找到采买，拿低价抢这笔单。主角按时交足约定的鱼，饭店见他供货稳，仍按原单收货，还约了下一批。主角才有机会接触县城订单。

## 长期反派的损失和结局

1. 在分集规划里标明哪些人会作为长期反派反复回场。第4–5集可以引入与首集冲突无关的新反派，再根据后续冲突安排是否长期使用。
2. 逐个记录长期反派每轮做了什么、已经失去哪些钱物、订单、资格或支持、还握着什么筹码，以及下次为什么会回来。前中期收完当轮冲突，让反派的损失持续影响后续行动。最终结局留到大结局。
3. 每个长期反派到大结局都必须破产，基本生计难以维持。让破产从前文的选择和实际损失一步步发生，并在场上逐个演出后果，例如卖店抵债、失去收入来源、最后连住处或基本开销都难以维持。一次性反派按当场冲突的实际代价收尾。

## 分集、自审和交接

1. **试抽前一事件。** 在规划和正文里试着拿掉前一事件。若下一事件的开场、人物动机和行动仍原样成立，改写前一事件收尾集的末场或下一事件的开场，让下一事件确实依赖前面已经发生的结果。再试抽整轮，检查后续选择、重要资格和结局有没有用到本轮结果。可以补回作用、合并重复事件，或调整本轮结果。
2. **试换两轮。** 如果调换顺序后，双方的资源、认知、关系和行动都无需改写，补清哪一轮先创造了另一轮需要的条件。并行的支线只要各自兑现且切换清楚，可以保留。
3. **查变化和可见证据。** 比较批首与批尾实际正文。角色说「信了」「怕了」「赚大了」以后，用选择、交易或交接动作坐实。检查伏笔、能力保密和承诺有没有提前说破或从此消失。
4. **跨阶段接续。** 写第11集和安排第31–80集前，分别以用户明确确认的第1–10集和第1–30集正文为准。第31–50集完成自审、去 AI 味和复核后，接到用户确认的第1–30集上，形成内部第1–50集。按其实际末场和已确认的分段大纲直接续写第51–80集。单独从已有稿中途续写时，按用户指定的版本承接。每次接续都核对上一集实际末场、人物状态、已发生的结果和未兑现的事项，再确定各线怎样接上。上一事件仍在进行时接住现场，从收尾结果引出新事件。
