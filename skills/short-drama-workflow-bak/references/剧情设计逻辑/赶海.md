# 赶海题材的剧情设计逻辑

以下五条都是硬性规定。挑桥段、做大纲、写正文和审稿都要逐条执行，漏了就补。只有用户明确提出修改具体剧情时，才按其要求调整该处，例外仅适用于用户指定的剧情。

1. **主角全程靠亲自出海打鱼、上岸卖鱼赚钱。** 从第一笔到大结局，钱都来自主角亲手打来的渔获。赚得多了，可以修房、换船，用一个结果带过，再回到下一趟出海。开鱼行、办加工厂、经营船队、复兴渔村或振兴行业都算主线跑偏。
2. **鱼获和处境都要让观众一眼看懂。** 以带鱼、鲈鱼、黄鱼这类常见称呼的鱼为主，可搭配大龙虾、螃蟹等大众熟悉的渔获。用鱼的大小、数量和上岸时的分量演出收获，人物遇到的事也落在渔村日常能碰到的处境里。
3. **打脸用家长里短的由头，点到就收。** 亲戚看主角穷，邻居笑他的旧船肯定空手回来，这样的小事就够开戏。卖鱼现场的小打脸，写对方看到主角打来的鱼和买家付的钱后改口或哑火，当场收掉，整段只算一次赚钱。单独排的打脸要写清[起因、发展、高潮、结果](../templates.md#打脸段四项)，演出反派实际吃了什么亏，再接回主角出海赚钱。主要反派和长期反派到大结局必须破产，惨到无法维持基本生活，具体写出他因前面的选择和亏损丢了什么、日子怎么过不下去了。
4. **把篇幅给找鱼、下网、收鱼和卖鱼。** 演清主角凭经验或金手指从哪儿找到鱼，怎样亲手抓到，最后带什么回来。渔网等用具随动作一带而过。发明或添置新渔具、研究设备、改装船都算跑题。换船时交代主角已经用上新船，接着演这趟出海打到了什么。

   **一趟出海写超过3集，必须拆成有明确收获的小段。** 长出海分三次演主角亲手打到东西。第一次是一堆小鱼，第二次收获更大，最后一次拿到单条或单只就值几百万的渔获。6集可用2＋2＋2，7集可用2＋2＋3，9集可用3＋3＋3。每小段都要把鱼实际抓到手，并按下条报出估价和收入对比。整趟跨写作批次时，继续原来的小段和收获顺序。

5. **每趟的主要渔获一到手，就报金额、做收入对比。** 当场让懂行情的人用一句家常话说出这一只或这一网约能卖多少钱，再用同年代、同地方的月工钱或普通渔民一趟的收入作参照。上岸卖鱼时演买家验货、称重、报成交金额并付钱，钱实际交到主角手里。
