# 短剧_转正文格式

将简约格式的剧本（`场景：xxx` + 一段话）转换为完整的正文格式——带场景编号、时间/内外、人物行、▲镜头分割和标准对话格式，与已有剧集的格式保持一致。

## 触发词

- `"转正文第X集"` — 单集（如"转正文第七十集"），文件通过 `@文件名` 指定
- `"转正文第X集到第Y集"` — 范围（如"转正文第70集到第75集"），文件通过 `@文件名` 指定
- `"转正文X-Y集"` — 简写范围（如"转正文70-75集"），文件通过 `@文件名` 指定
- `"格式化第X集"` / `"把第X集转成正文"` — 同上

## 输入格式与输出格式

### 输入（简约格式）

```
第七十集
场景：街道
一段话写完所有内容。李婉月OS：内心独白。王海VO：电话声音。李婉月赔笑：对话内容。说完做什么动作。等等等等。

场景：车内
李婉月急：师傅去机场快！司机：闲聊。等等。
```

### 输出（完整正文格式）

```
第七十集

70-1

日/外

场景：街道

人物：李婉月、王海

▲午后的街道上，阳光斜斜地洒落在路面上。李婉月独自一人走在路边。

李婉月OS: 内心独白。

▲手机突然震动，她低头看了一眼屏幕，按下接听。

王海VO: 电话声音！

李婉月(赔笑): 对话内容。

▲她挂断电话，把手机攥在手心，低头站在原地。

...

70-2

日/内

场景：出租车内

人物：李婉月、中年司机

▲出租车内光线昏暗，引擎低沉轰鸣。李婉月身体前倾。

李婉月(急): 台词！

中年司机: 闲聊。
```

## 格式规范

严格遵循已有剧集的正文格式：

- 每集以 `第X集` 开头为标题行
- 空一行
- 场景编号：`X-1`、`X-2`（一个场景一个编号）
- 空一行
- 时间/内外：`日/内`、`日/外`、`夜/内`、`夜/外`
- 空一行
- `场景：地点名称`
- 空一行
- `人物：角色1、角色2`（中文顿号或逗号分隔）
- 空一行
- `▲` 开头描述画面/动作（正文从此开始）

### 对话格式

- 普通对话：`角色名(情绪): 台词` — **括号里只写神态/情绪**（笑、怒、急、不屑、赔笑等），不写动作
- 画外音：`角色名VO: 台词`
- 内心独白：`角色名OS: 台词`
- 电话：`角色名(电话/情绪): 台词`

**动作不写在括号里，写在 ▲ 后面。** 比如"点头"、"站起来"、"掏出手机"这些动作，要用 ▲ 单独写一行描述，再另起一行写对话。

### 画面标记

- 每个镜头/场景切换用 `▲` 开头
- 可用镜头语言：`全景`、`特写`、`镜头推近`、`镜头切至`、`画面定格`
- 结尾可用：`切黑`、`画面模糊转黑`、`定格转黑`

## 转换规则

### 1. 拆场景
原文每出现一个 `场景：xxx` 就是一个独立场景，生成对应的场景编号（X-1、X-2...）。

### 2. 定时间/内外
根据场景正文内容分析判断，**不能只看场景名称**：

- **日夜判断**：看正文中是否有时间提示（"午后"、"黄昏"、"夜晚"、"天黑"、"清晨"等）。没有明确时间提示时，根据上下文推断。
- **内外判断**：看正文中的环境描述，判断是在室内还是室外。街道、路边、巷子等是户外；车内、店内、房内等是室内。
  
常见组合：
- 户外有阳光/白天 → `日/外`
- 室内白天 → `日/内`
- 户外天黑/夜晚 → `夜/外`
- 室内夜晚 → `夜/内`

### 3. 定人物
从该场景的正文内容中提取所有出场角色。**人物行必须包含场景中实际出现的所有人**，包括：
- 本人出场的角色
- 通过电话/VO出现的声音角色
- 被对话直接提及且有互动的角色

不能只写集纲里列的人，要看场景正文里到底有谁。**不要编造原文没有的人物。**

### 4. 拆分镜头（核心操作）
将原文的一段话拆成一个个镜头，每个镜头以 `▲` 开头：

- **动作/场景描述** → 单独一个 `▲` 段，可在后面加形容词丰富画面
- **OS/VO内心独白** → 单独一行，`角色名OS：内容`
- **对话** → 单独一行，`角色名(情绪): 台词`
- **连续动作** → 可合并到一个 `▲` 段里

### 5. ▲ 后面加形容词（给AI生成视频用）

这个剧本最终是给AI做视频用的，所以▲后面加形容词时，**只加对AI生成画面有帮助的信息**。

**有用（帮助AI理解画面）：**
- 光线/色调：`阳光斜洒`、`光线昏暗`、`逆光`、`暖光`
- 环境场景：`老旧街道`、`狭窄小巷`、`空旷大厅`、`繁华街口`
- 天气时间：`午后`、`黄昏`、`阴天`、`细雨`
- 空间构图：`近景`、`中景`、`远景`
- 色彩：`暖黄色调`、`灰白`、`昏黄`
- 物品位置：`路边的长椅`、`墙角的扫帚`
- 环境音：`引擎轰鸣`、`安静得能听到脚步声`
- 视角运镜：`镜头从上方俯拍`、`跟拍`

**不要加（对画面没用）：**
- 神态描写：`面色复杂`、`神色焦急`、`眼神坚定`、`表情冷漠`
- 内心感受：`心情沉重`、`内心挣扎`、`百感交集`
- 抽象描述：`空气中弥漫着紧张`、`气氛压抑`

**不能加原文没有的道具、物品、人物。** 比如原文没写"皮包"就不能加"提着皮包"，原文没写"下雨"就不能加"雨水"。

### 6. 对话格式转换
原文中的对话（如 `李婉月急：师傅去机场快！`）要转成标准格式 `角色名(情绪): 台词`。

**括号里只写神态/情绪，动作要放到 ▲ 段里。** 比如原文写了"李婉月点头说：好"，要拆成 ▲李婉月点了点头。 和 李婉月: 好。

**情绪可以自己推断添加：** 原文没写情绪的，可以根据场景和上下文推断这个人说这句台词时的状态——是笑是哭、是急是慌、是敷衍还是真心。挑关键台词加上就行，不用每句都加。比如原文只写"李婉月：好"，但场景里她正在敷衍王海，就可以写成 `李婉月(敷衍): 好`。

## 范围处理（批量转换）

当用户指定一个范围（如"转正文21-30集"）时，需要**逐集处理**：

1. **定位范围**：在文件中找到起始集（如"第二十一集"）到结束集（如"第三十集"）之间的所有内容
2. **逐集处理**：按顺序从第一集开始，一集一集地转换，**不允许跳集或并发处理**
3. **每集独立**：每集都有自己独立的场景编号（21-1、21-2...22-1、22-2...），互不影响
4. **每集完整**：每集都要完整走一遍"拆场景→定内外→定人物→拆镜头→加形容词"的流程
5. **每集都要符合本skill的所有格式规则**，不能因为批量就偷工减料

## 写作步骤

### 单集处理步骤：

1. 读取用户 `@` 指定的文件，根据集号找到对应段落
2. 识别所有 `场景：xxx` 行，确定有几个场景
3. 为每个场景生成：编号 → 时间/内外 → 人物
4. 逐场景拆分原文段落，将一段话分解为单个镜头：
   - 找出所有对话/OS/VO，提取角色名和情绪
   - 找出所有动作描述，转为 ▲ 段
   - 调整顺序，让画面流畅
5. 在 ▲ 段中添加形容词丰富画面，**但不添加原文没有的内容**
6. 将转换后的内容写回文件

### 批量处理步骤：

1. 读取用户 `@` 指定的文件，确定起始集号和结束集号
2. 在文件中找到起始集（如"第二十一集"）和结束集（如"第三十集"）的位置
3. **从起始集开始，逐集处理**：
   a. 读取当前集的简约内容
   b. 识别该集内的所有场景
   c. 为该集的每个场景生成：编号 → 时间/内外 → 人物
   d. 逐场景拆分该集的原文段落为单个镜头
   e. 在 ▲ 段中添加形容词丰富画面
   f. 进入下一集，重复步骤3a-3e
4. 所有集处理完成后，将全部内容一次性写回文件

## 示例

### 示例一：单场景

输入：
```
第四十五集
场景：饭店大厅
王海得意地坐在椅子上。李婉月走过来：老板，于老板那边来电话了，说要订酒席。王海眼睛一亮：真的？他可是大客户！李婉月点头：错不了，就等您回话呢。
```

输出：
```
第四十五集

45-1

日/内

场景：饭店大厅

人物：王海、李婉月

▲饭店大厅里，王海翘着腿坐在椅子上，满脸得意。

▲李婉月走到桌前。

李婉月: 老板，于老板那边来电话了，说要订酒席。

▲王海猛地坐直身子，眼睛一亮。

王海(惊喜): 真的？他可是大客户！

▲李婉月点了点头。

李婉月: 错不了，就等您回话呢。
```

场景：街道
李婉月独自在路边走着。李婉月OS：内心独白。手机震动，她按下接听。王海VO：电话声音。李婉月赔笑：回复。挂断电话。她掏出手机订了下午两点的机票。

场景：车内
李婉月急：师傅去机场！司机：放心来得及。
```

输出：
```
第七十集

70-1

日/外

场景：街道

人物：李婉月、王海

▲李婉月独自一人走在路边。

李婉月OS: 内心独白。

▲手机突然震动，她低头看了一眼屏幕，按下接听。

王海VO: 电话声音！

李婉月(赔笑): 回复。

▲她挂断电话，站在原地沉默了片刻。

▲她掏出手机打开订票软件，订了下午两点的机票。

70-2

日/内

场景：出租车内

人物：李婉月、中年司机

▲出租车内，李婉月身体前倾。

李婉月(急): 师傅，去机场，快！

中年司机: 放心吧，来得及。
