# 受辱库

第一集必须有受辱，且**只有一层**。但光是“被欺负”不够——观众要的是**男主掏心掏肺之后，被最亲的人捅一刀**。

## 一、情绪杠杆：先付出，再背叛

这是切入点的发动机。顺序不能反：

```
男主竭尽所有地付出 → 付出被最亲的人拿走 / 否认 / 反过来踩男主 → 观众炸
```

没有付出，背叛就只是一件倒霉事。观众不会为“一个路人骗了男主”生气，但会为“男主卖房供弟弟读书，弟弟转头把男主告了”暴怒。

**付出要具体、可见、倾其所有**：

| 付出什么 | 例子 |
|---|---|
| 钱 | 三年打工钱全寄回家盖了房 |
| 房子 | 把婚房让给弟弟结婚 |
| 学业 | 辍学供弟弟读书 |
| 身体 | 替爹还债累到吐血 |
| 名声 | 替弟弟背了偷东西的黑锅 |
| 机会 | 把进城名额让给弟弟 |
| 命 | 替弟弟挡了一刀 |

**背叛要拿走同一件东西**：男主盖的房被过户、男主让的婚房被占、男主供的弟弟说“你不配当我哥”。付出和背叛对不上，情绪就散了。

**男主必须占理**：男主没有错，没有贪，没有先动手。观众得觉得“换我也受不了”。

## 二、谁欺负男主：关系距离

| 级 | 施辱者 | 真实剧例 | 情绪 |
|---|---|---|---|
| A | 配偶、未婚夫 | 《八零弃妻》：被丈夫为转正名额抛弃 | 最痛 |
| A | 父母、亲兄弟 | 《弃子重生》：被偏心父母和白眼狼兄弟抛弃 | 最痛 |
| B | 大伯二叔、舅舅、堂表亲 | 《七零小福星》：恶霸舅舅（也做友方） | 很痛 |
| C | 邻居、同村、同事 | 《神龙分身》：眼红村民 | 一般 |
| D | 陌生人、权贵 | — | 弱 |

**取 A 或 B。** C 级只能在没有更好样本时用，并注明；D 级不用。

## 三、怎么欺负：受辱类型

按强度排，越靠上越好：

1. **夺生存资料**：粮、房、地、救命钱被拿走
   《荒年赶山》：荒年断粮；《重生北地》：家里断粮
2. **被抛弃**：赶出门、扔下不管、送走
   《弃子重生》：老年被家人抛弃，惨死桥洞
3. **否认付出**：“你在这个家出过一分力吗”
   《七零小福星》：亲妈把三岁半的孩子当扫把星遗弃
4. **当众羞辱**：祠堂除名、婚礼退婚、分红划名
5. **身份否定**：你不是我家的人、这孩子不是我们家的种

## 四、特殊时间锚点

受辱不能发生在平常的一天。**必须绑一个躲不开、人都在、错过就没的日子。**

三个作用：众人到场、不能改天、对比强烈（这天本该是喜事）。

**通用节点**：除夕 / 年夜饭 / 婚礼 / 订婚宴 / 满月酒 / 老人葬礼 / 分家当天 / 交租日 / 分红日 / 拆迁签约 / 发薪日 / 生日 / 结婚纪念日

**题材节点**：

| 题材 | 可用节点 |
|---|---|
| 赶海 | 开海第一天、大潮日、台风前、收购商开秤、分船位那天、年三十最后一网 |
| 赶山 | 放山第一天、开山季、秋猎开山日、山货开秤、封山前最后一天 |
| 鉴宝 | 拍卖会当天、行里开眼日、老爷子寿宴 |
| 两界双穿 | 年三十最后一趟货、赶集日、两边同时过节、收税日 |

**禁用**：“有一天”“某天”。没有锚点，受辱就变成背景交代。

## 五、五条硬规矩

1. **只许一层。** 抢粮就抢粮，出轨就出轨。两件事一起上，第一集就乱。
2. **必须先后付出。** 没有倾其所有的付出，背叛不成立。
3. **受辱要落在地上。** 不能是“被看不起”这种虚的，要有一个具体动作：拿走、赶走、当众念出来。
4. **时间必须特殊。** 分家、除夕、满月酒、开海第一天。
5. **男主占理。** 男主没做错任何事，观众得觉得“换我也受不了”。
