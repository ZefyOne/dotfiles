# 剧名公式

红果剧名不讲含蓄，一句话交代三件事：**谁受辱 → 靠什么 → 得到什么**。

**默认男频**：剧名按男主视角写；下面的女频样本只作公式参考。

## 真实样本（赶海 / 赶山，2026-11 采集）

- 赶海：我能看透整片大海
- 千禧赶海：我能看透整片大海
- 我有神龙分身，狂捞海底宝藏
- 弃子重生，赶山发家只疼老婆
- 八零弃妻，我带魔丸赶海成渔王
- 重生北地，我赶山养全家
- 七零小福星：赶山带恶霸舅舅暴富
- 荒年赶山，白虎报恩助我救赎全家
- 赶山捡到小狐仙，号令万兽山货装满筐
- 全家被送荒岛后，我成了赶海女王

## 六个公式

**1. 题材 + 能力宣告**（冒号式，最短）
赶海：我能看透整片大海
千禧赶海：我能看透整片大海

**2. 受辱身份 + 手段 + 结果**（最贴我们的要求）
八零弃妻，我带魔丸赶海成渔王
弃子重生，赶山发家只疼老婆

**3. 手段 + 情感承诺**（打养家牌）
重生北地，我赶山养全家
重回千禧我靠赶海养活家人

**4. 奇遇 + 产出奇观**（给画面感）
我有神龙分身，狂捞海底宝藏
赶山捡到小狐仙，号令万兽山货装满筐

**5. 年代标签 + 关系 + 暴富**
七零小福星：赶山带恶霸舅舅暴富
重生1983，带着五六半去赶山

**6. 极端处境 + 翻身**
荒年赶山，白虎报恩助我救赎全家
全家被送荒岛后，我成了赶海女王

## 硬约束

- **12 字上下**，最长 18。
- 必须出现**手段词**：赶海、赶山、捡漏、鉴宝、倒卖。
- 受辱类标题把受辱写进前半句：弃妻、弃子、被送荒岛。
- 后半句给结果承诺：暴富、成渔王、养全家、装满筐。
- 一个标题只装一个奇观。三个设定挤进去，观众一个都记不住。

## 三个候选怎么配

同一提案给三个，走不同公式，覆盖面才够：

- 一个走公式 2（受辱+翻身，最直给）
- 一个走公式 1 或 4（能力/奇观，抓眼球）
- 一个走公式 3 或 5（养家/年代，稳受众）
