# 剧情循环

## 定本剧反复兑现的看点

- 先按[长线标准](long-arc.md)确认本剧采用几条线，构思这些线怎样互相推进，再从简介和题材拟定本剧的循环。用这部剧的具体本事、收获和冲突写明主角反复怎样行动、胜利换来什么、本轮结果如何打开下一轮。沿用用户已定的核心环节和顺序，尚未规定的顺序按本轮因果安排。新剧在对话里注明采用的线数，把拟定的循环和[节奏方向](pacing.md#新剧先确认节奏方向)一起交用户，只确认尚未定下的内容。循环和节奏定下后，再按各集段的任务选桥段。
- 排篇幅时只对「主角收获赚钱」和「打脸反派」两块按[阶段节奏](pacing.md#后续阶段按剧情调整篇幅)酌情加集。赶海抓鱼、卖货和鉴宝捡漏、验货、成交，都归入主角收获赚钱。反派找事、主角亮优势反击、反派付代价归入打脸。反派可以在卖货现场找事，两块可以按本轮因果交错。改善生活和带出下一轮的衔接按剧情安排。不含买卖的题材用本剧可见的成果兑现对应看点，例如神医当场治好病人。
- 将简介指定的开局事件和全剧收束节点放在对应位置。沿用用户已确认的开局和同题材节奏文件实际覆盖的部分，再用[前十集默认节奏](pacing.md)补足，例如第1集受挫后觉醒金手指，再进入第一轮。最后一轮的结果用来兑现全剧目标，第80集收束全剧。

## 把素材中的小剧情改成本剧的一轮

第1–10、11–30、31–50、51–80集都按已确认的循环和节奏，用[素材改编标准](source-adaptation.md)从启动时确认的拆解记录选出本轮的收获、冲突和结果。用户指定的具体事件直接采用。关键环节缺合适的素材时，在对话里注明缺口，等用户补素材或给具体安排，先处理已有依据的部分。

1. 写清本轮起因和主角眼前要办成的事。反派来找事时，优先从主角刚拿到的成果找起因，交代反派怎么得知、能争到什么或怕失去什么、为什么现在出手。
2. 确定选出的桥段中，主角用本剧的能力或优势做了哪个关键判断，亲自做了什么，现场出现什么可见结果。写清收获怎样拿到、冲突怎样解决、得失怎样兑现。需要打脸时按[打脸标准](face-slapping.md)落实出手、反应和代价。
3. 留下本轮具体变化，比如钱交到谁手里、家里添了什么、拿到哪个订单、谁开始信主角、谁因丢了利益改变做法。把这一轮的结果交给 [长线推进](long-arc.md)，用来推下一轮的起因或全剧目标的下一步。
4. 对照前一轮，检查收获、反派找事的动机、双方筹码和结果。保留题材核心的胜利方式，把变化写进人物遇到的问题、主角的选择或结果的代价。两轮只在鱼名、货名或反派名字上有差别时，换更适合的素材，或用本剧已有的利害改出不同的冲突。

将每轮压成一句可核对的因果描述。因某件已发生的事，人物为了某个利益做出某个行动，主角用具体办法解决，现场留下具体结果。因果成立后，按 [节奏标准](pacing.md) 已确认的篇幅拆集。

## 赶山赶海的开局和收获

- **开局给观众翻身的盼头。** 从正在发生的欺负、排挤或夺利切入，用反派的具体行为和简短对白让观众听懂关系、利害和主角受的亏。默认第1集末觉醒金手指，第2集让主角试用能力，作出一个决定或采取行动，拿到第一次收获。已有确认的开局按本剧排法执行。
- **把收获演到手。** 让观众看见主角发现了什么、凭什么判断、金手指或经验怎样帮助获取、成果如何拿到。现场有阻碍时，演主角临场怎么应对。压缩走路和普通寻找，把篇幅留给发现的惊喜、决定成败的动作和旁人看到实物后的反应。
- **让每轮有新看点。** 从收获种类、取得方式、现场难题或争夺利益里选一个真正影响行动或结果的变化。比如上一轮靠认潮找到鱼，这一轮要在水位上涨前把鱼带走，主角就需要作出新的取舍。
- **让钱落到日子里。** 卖货后用一场戏看见钱解决了什么，例如修好漏雨的屋顶，或换来能装更多货的工具。家常互动可以表现关系变化，也可以带出下一步决定。若收获或生活变化引来反派，写清反派怎么得知、想拿什么，以及为什么现在动手。
