# 剧情检验

在分集规划送确认前和每批正文交付前各检查一次。使用当前题材的循环、已确认节奏和项目长线。先定位问题所在的集、场或剧情节点，再决定修法。

## 分集规划检查

先核对规划是否注明用户确认的线数和各线内容。检查上一轮的结果怎样引起下一轮的冲突或关系选择。试着抽掉上一轮，下一轮若仍能原样发生，先补清两轮之间缺少的因果。跨阶段先确认已主动询问并收到用户对累计定稿 Word 的明确答复，再用定稿正文核对实际留给本批的前因。

第1–10、11–30、31–50、51–80集都按[素材改编](source-adaptation.md)核对用户未指定的关键剧情。对照启动时确认的拆解记录，指出原稿、集数和对应场面，说明这段如何完成已排好的剧情任务，以及换成主角本事和当前人物关系后，为什么会发生、结果如何带出下一件事。关键剧情缺合适素材时，在对话里列出具体缺口。等用户确认当批剧情和卡点后，再写正文。

1. 给每集标出它完成的循环环节，或承接的开局、结局、已定长线节点。具体写出集内发生的变化和由此引起的后续行动。只写「继续赶海」「反派再来找事」时，补出本集事件和独有结果。
2. 顺着场景问下去。人物从哪里知道这件事，为什么现在做，凭什么能做成，做完以后谁能或必须改变下一步。拟写关键台词前，按[台词标准](dialogue.md)核对说话人从哪里得知信息、能判断到哪一步。缺少依据时补前因或换做法，优先利用前面已有的钱物、人物关系和承诺。
3. 按[阶段节奏](pacing.md)核对各轮起止集数。定前十集的基准篇幅时，先粗排全剧各轮，确认能在第80集收束。后续只对「主角收获赚钱」和「打脸反派」两块考虑比上一阶段多约2集，按剧情需要取舍，每集都要有新进展。跨批旧轮按已确认的排法写完。第51–80集可为连贯收束加快或放缓，涉及已确认排法时先交拟改方案。第80集必须完成全剧结局。
4. 第1–79集按[卡点标准](hooks.md)写清本集停在哪里、观众具体等什么、下集开场怎么接。用震惊卡点时，再核对是否属于打脸高潮或主角在集尾首次认出有分量的值钱物品，写明说话人、现场依据和末句原文。第80集查结局怎样收束。
5. 按[长线推进](long-arc.md)逐个检查事件交界。写明前一事件实际留下的结果、收尾集里谁用哪个动作或哪句话把结果变成下一事件的机会或麻烦、下一事件开场由谁接住并采取什么行动。把前一事件抽掉试一遍。下一事件若还能原样发生，就补两者之间的因果。用震惊台词收尾时，提前演出后续所需的线索，或由这句台词直接点出。新人物、新支线或突发麻烦同样要接到已发生的事，并写清它对循环或已定长线的作用。
6. 多集打脸按[打脸剧情](face-slapping.md)检查情绪起落。七八集的长打脸可分两三个阶段，逐段核对反派施压、主角小反击和下一轮更强的压力。各次小反击要实际改变处境，阶段末顺着当下进展选卡点。查已定的高潮集是否亮出决定胜负的优势，让打压主角的反派亲眼见证，用他当场被震住的第一句台词兑现打脸。未指定的其他多集段落通常在该段倒数第二集末亮优势。收尾集接原现场，演完反派的反应、实在的损失和离场。

## 核对开局节奏与高潮承接

在节奏、分集和正文各阶段，以本剧已确认的排法为准，依次用同题材节奏文件和[前十集默认节奏](pacing.md)补齐空缺。采用默认排法时，核对首集觉醒后的卡点、第4–5集的独立冲突结果，以及第8–11集怎样回应首集的羞辱。售卖按题材落实，也可用实际验证的服务成果或同等收益承担这一功能。按本剧已确认的高潮集查主角当场亮出的优势和反派的震惊末句，再查下一集如何接原现场，兑现主角所得、反派的反应和代价，并用结果带出下一事件。一段连续剧情尽量由一两个主要场景承载。

## 正文检查和改法

- 做删场测试。先抽去这一场或重复的一小段，顺读前后。若人物决定、后续结果、必要的铺垫和情绪力度都一样，删掉或把有效信息并进相邻一场。见证、关键反应和兑现的动作会改变观众对结果的感受，结合前后整轮戏判断其价值。
- 检查关键戏有没有真正发生。抓到东西要在场上看见拿到，谈成生意要让观众看清谁买、谁收钱。连读打脸前后的场面，看优势怎样推翻反派的放话。小反派求饶的狼狈要接得上此前的嚣张，长期反派仍不服。用动作和台词写出他实际丢了什么、怎么肉痛，再演离场。
- 主角受辱、遭背叛、局面反转和反派被打脸时，找出人物当场看见或听见的触发点，核对紧跟的动作与台词是否撑得住这件事的分量，以及它怎样影响人物的选择或带来实际后果。暂时遮去「震惊」「愤怒」之类的语气括注，单看动作和对白仍应能读出反应。逐场对白按[台词标准](dialogue.md)复查。
- 检查第1–79集末尾。普通卡点从本集已发生的事带出具体期待，下集开头接住决定、待揭晓的关键结果或新摆到眼前的难题。用震惊卡点时，查反派是否当场见证主角优势，或主角是否当场首次发现有分量的值钱物品。去掉「（震惊）」和最后一句，检查前面演出的事实是否撑得住反应。用已知信息再制造一次发现，或临时添事硬凑卡点时，顺着本集已有进展换收法。涉及已确认内容时先提交改法。
- 连读前一事件收尾集的末场和下一事件的开场。对照实际正文指出前一事件留下的结果、谁在收尾场用什么动作或台词引出下一事件、开场的人怎样接住。抽掉前一事件后，下一事件仍能原样发生时，补到两边都接得上。批次末尾的后续正文尚未写出时，核对已有收尾场和承接计划，实际开场留待续写复查。
- 重读本轮和相邻集，核对行动先后、时间地点、人物知情、钱物去向、承诺和后果。改动某一处以后，回查它牵动的集尾、后续集的承接及已写的结果。第80集核对最终兑现。
- 在已确认的剧情、节奏和卡点范围内，优先围绕原桥段微调动机、衔接、动作和台词。确需更换关键剧情时，从已通读的样稿拆解中挑替代桥段，或依据用户给出的具体安排。提交集数、当前写法、拟改法及受影响的集数，待用户确认后落实。缺可用桥段时注明缺口。
