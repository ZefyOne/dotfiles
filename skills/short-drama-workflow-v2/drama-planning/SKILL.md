# 短剧剧情规划

先安排完整故事的因果，再按五个写作阶段逐步细化。规划负责谁在何时做什么、人物彼此怎么看、每集在哪里停以及下集怎么接。动作对白的具体写法交正文写作。已经确认的工作直接接用，按本次请求的集数和任务返回结果。

## 新剧启动

1. **确定题材，学习样稿。** 用户只说写新剧时，第一轮只问要写什么题材。知道题材就用技能目录下的 `assets/<题材名>/`，按[样稿学习](references/source-study.md)逐份通读 Word 到实际末集；先读已有的题材设计逻辑。给用户看几个有出处的案例，等用户认可对该题材的理解。记下代表性对白的集场和用法，供写作时回读。
2. **收本剧设定。** 沿用用户给的剧名、简介、年代、开局矛盾、人物关系、已有情节；集中补问影响构思的缺项。必需有题材简介，几句话即可。金手指的本事和用户想看的爽点都要说得清：只知功能时，问「你最想看主角用它做成什么事？」线数未定时问「这部用双线，还是加感情线做三线？」等答复再排剧情。用户给了自订主线、节奏或分集，就照其安排。
3. **提循环和节奏方向。** 用[长线、循环与节奏](references/arc-and-pacing.md)串起主角靠金手指取得收获赚钱的主线、由收获引起的反派线，以及已选的感情线。读题材节奏表，先报所用线数、循环，再由 AI 给出前十集默认集段和各段任务，请用户微调。若已经写到具体人物交手，就用[节奏初稿格式](references/templates.md#节奏初稿)把双方的看法和打算一起发出来。已有明确排法可直接采用，逐集卡点在详排时提交。
4. **内部完成第1–80集粗纲，反推初始人设。** 根据已确定的循环，按连续集段排到大结局，每段要有具体事件、关键人物、结果和下一段的来由。倒看第80集怎样回应首集的损失，主角如何保持原本赚钱方式，所有长期反派如何破产、难以维持生活，已定关系怎样收束。第1集与第8–11集一起推演。按全剧实际需要确定重要人物，包括中后段才登场的人，记下出场原因、相互关系和后续用途。用样稿中的设计方法和本剧已定的人物、利益、资源构思新事件。
5. **交第一版年代背景和人设，等用户明确确认。** AI 根据简介主动提出具体版本，按[初始人设模板](references/templates.md#年代与初始人设)在对话里展示。用户改身份、关系或性格，先在内部更新受影响的出场、动机和后续事件，再确认所改内容。确认后才发第一集详案。全剧粗纲平时内部沿用，用户要看时按其要求展示。人物小传、正式简介和梗概留到完本。

## 题材资料与规则优先级

逐题材查同名的 `references/剧情设计逻辑/<题材名>.md` 和 `assets/各种题材节奏/<题材名>.md`。当前[鉴宝设计](references/剧情设计逻辑/鉴宝.md)配[鉴宝节奏](assets/各种题材节奏/鉴宝.md)，[赶海设计](references/剧情设计逻辑/赶海.md)配[赶海节奏](assets/各种题材节奏/赶海.md)。两界双穿有同题材样稿，尚无专用设计表或节奏表。遇到这些空缺就根据本剧设定和通用标准提议，不套其他题材的特殊限制。

依次采用用户本次明确要求或已确认的安排、该题材的硬性设计逻辑、题材节奏与通用标准。节奏表里的默认任务和篇幅用于排戏，其中举的事件或台词只作参考。素材中的安排也须符合本剧人物与金手指，用户直接指定的剧情优先。观众看懂主角凭什么赢即可，配角看见结果可以直接服气；人物说出某个姓名、秘密、交易条件之前，必须有机会知道它。

## 按阶段交规划

每次先读本次采用的定稿和上一集实际末场，核对人物态度、资金道具、当场知情及未兑现事项。已有主控提供的本阶段定稿确认就接用；基准未明确时，先核实哪份算数。各阶段使用同一套题材逻辑。一个事件可以跨第1、10、30、50集的交界，创作批次起止不会自动结束这场戏。

| 写作阶段 | 规划的起点 | 提交和细化 |
| --- | --- | --- |
| 第1集 | 已确认的年代、人设、开局和节奏 | 单独交首集详案，请用户确认。先写清主角不求回报的重大付出、对方怎样理所应当地伤害主角、主角为何离开。明确金手指在本集怎样首次生效、主角最后如何惊讶地说出它的作用，以及此事怎样埋下第十集的期待。 |
| 第2–10集 | 用户指定的第1集正文定稿 | 重新核对先前设想，逐集交剧情、分段人物心理和卡点，请用户确认。把第10集与第11集的接法一起交清：默认第1集的反派现场见证主角亮优势，第10集末卡他的第一句震惊，第11集才演完代价和离场。 |
| 第11–30集 | 用户指定的第1–10集正文定稿 | 接第10集实际停笔的一刻；已发生的事实以定稿原文为准。逐集交本批规划，请用户确认后交写作。 |
| 第31–50集 | 用户指定的第1–30集正文定稿 | 对外一次交连续覆盖第31–80集的分段大纲。确认后在内部将第31–50集具体拆到每集、每个卡点，交写作。 |
| 第51–80集 | 已通过复审的第31–50集与指定前30集组成的前50集实际正文 | 读第50集末场，沿用已确认的后五十集大纲，内部细化余下集数，第80集写完结局。单独从第51集接写，则用用户指定的前五十集，就本次第51–80集的大纲确认。 |

## 细化、自查与交接

- 按[阶段规划模板](references/templates.md)先把一段交往的起因、发展、结果与下段接法串清，再逐集分配新进展。每个打脸段按[打脸标准](references/face-slapping.md)列齐**起因、发展、高潮、结果**和各自集数，写明主角的优势、反派的实际代价。
- **给用户的每段对手戏单列「人物心理」。** 用一行或表格一栏写各方怎么看对方、准备让对方做什么，临时买家和摊主也算；同一交锋跨集只列一次。独处只写行动和所得。用户要微调、简短版或只重发几集时，直接套[局部修改与简短重发](references/templates.md#局部修改与简短重发)。
- 逐集按[卡点标准](references/hooks.md)写实际进展、停笔位置、观众期待和下集怎么接。冲击靠人物一句话兑现时给出拟用末句，区分用户指定的原话与可由写作润色的措辞。第80集写收束。发出前用[交付前检查](references/templates.md#交付前检查)核对要给用户看到的内容。
- **确认后交[正文写作](../drama-writing/SKILL.md)。** 交前文版本、已定人设与用户修订、当前范围、已确认规划（含各段人物心理）、拟用和指定的末句、适用于本段的样稿位置。写作前优先回读本剧手改定稿；对应素材只回看本段交锋最相近的原场，完整对白和前后动作已在交接中则直接使用。
- **规划退回时只修受影响部分。** 区分本次更改只针对某句话、某个事件，还是此后持续适用的关系态度。取消前因时清掉后文依赖它的出场、信息和约定。未展示的安排内部更新；牵动用户已确认的重要事件、节奏、卡点或定稿时，说明具体集段与改法，等用户决定。用户定稿中的疑点只指出位置，受授权的新规划从实际定稿承接。给主控返回本次采用的规划版本、确认范围和下一步，不代写正文。
