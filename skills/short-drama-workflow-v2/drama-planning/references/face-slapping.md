# 打脸剧情

先定主角这回用哪项已知优势反击。让观众提前看见这张底牌，再让反派带着自己的误判，偏偏拿这一点嘲讽、作践或为难主角。写足观众替主角生气、迫不及待想看他亮出本事的过程。观众等的是反派亲眼被打脸、当场被震住和随后被收拾。规划完整打脸段时，将下列四项实写在发给用户的规划里。

| 四项 | 规划要交代的内容 |
| --- | --- |
| 起因 | 什么已发生的事让反派现在来找事？他想拿走或保住什么？写清他怎样看待主角，主角此刻怎样看他，以及在场的买家、证人等为什么会参与。 |
| 发展 | 观众什么时候已经知道主角有这项优势？反派怎样针对这一点持续羞辱、加压，逼主角让出什么？主角受压时仍能制止、拒绝、护人或转身离开。决定输赢的底牌留到最有用时亮。 |
| 高潮 | 哪一集、谁的什么行动使这项优势当场坐实，推翻反派判断？打压主角的人亲眼见证，让本集停在他认出优势后脱口而出的第一句震惊台词。见[震惊卡点](hooks.md)。 |
| 结果 | 接同一现场，先写反派震惊后的反应，再演有多肉痛、代价什么时候真的付出、他怎样离开、主角得到了什么。结果继续影响下一件事。 |

### 选择能回应本轮嘲讽的优势

- **身份优势。** 原先隐瞒的身份，或主角凭自己的作为赢得的新身份。大佬可以亲口作证，反派震惊的是主角竟是救过大佬的人。
- **信息优势。** 主角知道足以改变局势的关键信息，已据此作出选择。现场事实可自行揭晓，配角可用已交代的价格、成本算出所得。功劳落在主角的判断上。
- **资源优势。** 人无我有、人有我优。观众先知道主角拿到了什么，高潮一亮出实物，反派就认出其分量。
- **实力优势。** 主角用医术、身手等本事当场做成对方断言做不成的事。知情人或现实结果可以验证，荣耀始终归于主角。

排高潮时，把发展里反派拿来压主角的那句断言和高潮里他亲眼看到的事实并排读：看过这个事实，他还能原样说那句话吗？如果还能，先保住用户已定的戏，再改可调整的一端。用户定了亮什么优势，就让反派针对这项优势打压；用户定了嘲讽原话，就安排足以推翻它的现场结果。两端都已定且相冲时，指出具体冲突请用户决定。末句只惊在主角刚证实的这项优势上。旁人撑腰、买价便宜或碰巧走运，都不能代替主角的本事。去掉震惊台词，观众也该一眼看懂反派输在哪里。

### 长段怎样拆集

七八集的长打脸通常拆两三个小阶段。每阶段让反派施加一个具体压力，主角小反击，在现场改变一项得失。对手为了挽回这次损失，再动用手里更有分量的人、权或钱。小阶段之间可以停在决定、新难处或小结果。让压力逐级加大，把足以决定整段胜负的优势留到总高潮。反复骂同一句和重复查同一件事撑不起加长的篇幅。

多集打脸以用户和题材已定的集数为准，通常倒数第二集末亮优势，接约一集演反应和代价。一场戏里的小打脸可就地完成四项，无须独占一集。小反派前面有多嚣张，后来就有多狼狈，求饶也要真正赔出舍不得的钱物、交还机会或丧失资格。长期反派输了仍不服，离场后只能动用尚存的筹码。收住本轮损失，等到大结局逐个兑现破产和难以维持生计的具体后果。末轮可以随情节压缩，确保第80集把终局演完。
