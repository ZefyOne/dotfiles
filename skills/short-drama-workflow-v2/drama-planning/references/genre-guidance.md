# 题材建议

本文件按题材提供可选的剧情推进方式、爽点循环和常见问题。只有当前项目采用对应题材时，才读取相应章节。用户已经确定的设定优先于本文件中的所有建议。

## 赶海题材

- **核心爽点**　主角凭本事或金手指找到别人错过的大货，亲手捕到、卖掉，让观众看见这一趟赚了多少钱。
- 让观众看见发现、判断、捕捞、上岸、卖货和收款，写清收获与实际收益。
- 鱼获使用观众熟悉的称呼，用大小、数量和上岸分量表现价值。
- 卖货段可以安排验货、称重、报价和付款，让收益真正落到主角手里。
- 一趟赶海较长时，可以按小收获、较大收获和值钱大货推进，让每段都有看得见的结果。
- 如果用户把赶海和卖货安排成连续段落，可以参考用4—5集完成一轮。
- 当天能够完成的行动尽量放在同一条行动链里，没有剧情原因时不要拖到第二天。
- 每轮收获尽量更换目标和取得方式，安排观众能直接看见的强画面节点。
- 修房、换船和生活变化可以快速带过，再回到主角亲自赶海赚钱的主线。

## 鉴宝题材

- **核心爽点**　旁人当作便宜货的物件，主角看出价值，低价拿下，高价成交。观众先知道他捡了漏，再看这件东西卖出多少钱。
- 开局让观众听懂主角身份和处境，捡漏价值来自普通观众能理解的物件和差异。
- 先让主角用金手指发现，再亲自取得，随后用鉴定、报价、成交或现场结果坐实判断。
- 让观众看懂常人为什么看走眼，也看懂主角为什么赢。收益可以从小到大递进，成为下一笔买货的本钱。
- 用户没有要求时，少安排行业科普、文化传承、上价值和复杂专业解释。

## 双穿题材

- **核心爽点**　同一件货，一边买得便宜，带到另一边能卖出高价。观众知道本钱和售价，价差越大，成交时就越爽。每个高价都要有买家愿意付钱的理由，由当地的供需、用途或已建立的行情支撑。
- 现代常见的货带回过去，先交代当地为什么缺、谁急着买；从过去带回现代的野生或家养好货，写出买家能看得懂的品质差别，让高价有着落。
- 每轮写清在哪一界进货、花多少、带到哪里、谁按什么价买，以及收益怎样用于下一轮。两边的买卖可以接成往返，只安排本轮剧情需要的交易。
- 选普通观众认得、知道用途的货物。随剧情持续换货，让不同的两界需求带出新的生意，不能只换名字、反复写同一笔买卖。
- 两界的身份、人际关系、消息来源和生活逻辑要分开记录。一个世界发生的事情不能无依据地被另一个世界的人知道。
- 穿越方式、次数、携带限制和时间关系根据用户设定确定。没有确定时，只补足会影响交易因果的最少规则，不要为了说明机制堆复杂设定。
- 两界的钱分开记，注明各自币种、本钱、实收、支出和结余；应收或欠款单列，库存记清数量和所在的一界。钱货真正带过去或兑换后再记入另一边，不把不同币种直接相减算利润。报出余额前，按该界上次结余和本轮实际收支复算。
- 主角得到收益后可以改善生活、扩大本钱或解决现实麻烦，但主要爽点仍然来自两界倒卖本身。
- 反派一定不能知道主角的秘密，也就是金手指，连探查主角金手指的行为都不要有。
- 交易段和反派段要互相推动。主角刚靠一批货改善处境，新的货源、市场竞争或反派盯梢就可以引出下一轮。
