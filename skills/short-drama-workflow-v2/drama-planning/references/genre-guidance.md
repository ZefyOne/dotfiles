# 题材建议

本文件只写两件事：这个题材的核心爽点是什么，按什么框架写。写得短，是因为规则一长就会被稀释。只读当前项目采用的章节，用户已经确定的设定优先于本文件。

## 通用框架

- **核心爽点只有一个**：主角靠金手指（或独家本事）用什么手段赚钱。全剧每一轮都落在这件事上，赚钱方式不换。不知道核心爽点是什么，直接问主编，不要自己编。
- **辅助爽点只有两种**：打脸、花钱。也可以是花钱的过程中打脸——反派看不起认为他没钱、穷，主角当场展露财富，反派震惊。
- **打脸的落点只有反派震惊**。前面反派嘲讽得越狠，这一句震惊越响；观众追的就是反派震惊的反应。旁观者叫好、买家抢货、主角自证、旁白总结，都不能代替反派那一下。
- **打脸三拍**：反派先立一个错误判断（你不行、你没钱、你办不到）→ 主角当场亮出结果（钱、货、身份、成交）→ 反派震惊说一句，停在这句上。
- **不许出现第二个核心爽点**，不许把赚钱方式换成创业、投资、感情或别的故事。

## 赶海题材

**核心爽点**：主角靠金手指在海里找到别人找不到的大货，亲手捞上来、卖出去，观众看见这一趟赚了多少钱。

**题材框架**：

- 一轮：出海找位置 → 发现 → 动手捞 → 上岸验货称重 → 卖货 → 收钱。
- 要围绕着核心爽点去写。通常就是赶海一次，打脸一次，再赶海再打脸。这么来回循环。
- 一趟可以分小收获、大收获、值钱大货，让每段都有结果。
- 全剧只写赶海赚钱。修房、换船、生活改善快速带过，不写开公司、投资、养殖场。

**不能跑偏**：每轮必须亲自下海；货要观众认识，一轮换一种；金手指不能露。

## 鉴宝题材

**核心爽点**：别人当便宜货的东西，主角用金手指看出价值，低价拿下，高价卖出。

**题材框架**：

- 一轮：逛摊或收货 → 看货 → 试探压价 → 拿下 → 把货卖出去 → 卖的过程，买家震惊货有多么好 → 高价成交。
- 围绕着核心爽点去写，通常是鉴宝一次，打脸一次，来回循环。
- 收益从小到大，上一笔成为下一笔的本钱。
- 全剧只写捡漏赚钱，不写开公司、不做行业科普、不拔高文化传承。

**不能跑偏**：让观众看懂别人为什么看走眼，也看懂主角为什么赢；金手指不能露。

## 双穿题材

**核心爽点**：同一件货，一界便宜拿、另一界高价卖，价差越大越爽。

**题材框架**：

- 一轮：一界低价收货 → 带过去 → 另一界找买家 → 高价卖出 → 回程。
- 要围绕着核心爽点去写。中间插入打脸剧情。
- 随剧情持续换货，不能只换名字、反复写同一笔买卖。
- 全剧只写两界倒卖，不写别的生意。

**不能跑偏**：每笔写清本钱和售价；两界钱分开记，消息不互通；每个高价要有当地缺货或品质差别的理由。

**穿越规则**：方式和次数按用户设定，没确定就只补会影响交易因果的最少规则。金手指不能露。

## 其他题材

用户给别的题材时，先问主编一句话：主角靠什么赚钱、靠什么本事翻身？这句话就是核心爽点，不要自己编。

然后按同一套框架写四样：核心爽点一句话、一轮动作链、反派怎么嘲讽、打脸落在反派震惊那句上。

没有赚钱主线时，把“赚钱”换成这个题材的兑现物：复仇剧是反击进度，情感剧是关系进展，但只留一个核心爽点，其余全算辅助。
