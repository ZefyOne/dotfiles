# 学习同题材样稿

## 确认实际读过的内容

在 `assets/<题材名>/` 按需直接找每份 Word 剧本，读取每份实际正文，从首集读到它的末集。长稿按连续集段分块。记住各稿实读范围、关键集场和这一段的前后文。目录缺失、空稿、缺集或提取失败时说明实际缺口，请用户补充、指定素材或决定按已有设定继续。用户新补的稿子依此阅读。文件名上的集数不能代替实际阅读。

## 一段完整戏学什么

| 读样稿时关注 | 读到能说清的程度 |
| --- | --- |
| 题材的收获与兑现 | 主角发现了什么，靠自己的哪一步判断或行动取得好处，别人能亲眼见到什么结果，收益怎样拿到手。观众在哪一步先知道优势，最想看到怎样的兑现。 |
| 人物的来意与交锋 | 交手双方起初怎样看对方，各自要保住或争到什么。上一句话、动作或眼前物件，怎样让人抬价、松口、伸手、拒绝或离场。 |
| 观众情绪与打脸 | 反派怎样针对主角现有优势施压，主角露出什么让他立刻失势，谁亲眼见证，反派实际付出怎样的代价。 |
| 段内节奏与停笔 | 每一集新增的进展、原稿实际卡在哪里、下一集从哪一刻接上。辨清能拉住观众的停顿和拖长交易的套话。 |
| 事件之间的因果 | 上一段已得到的钱、货、关系或决定，如何让下一件事发生。把已完成的事收住，留下能解释下一步的结果。 |

交给用户的案例只选几个。给出题材、剧名、实际集数和可定位的场景，把原事件、高潮落点、收尾及自己学到的设计讲清楚。鉴宝优先展示一次纯收获、一次独立打脸、一次鉴宝过程中遇到打脸；其他题材替换为相应的收获和冲突。某类案例没有在样稿中找到时，就展示实际有的类型。等用户认可对素材的理解，再进入本剧设定。

## 把有用的打法交给新剧

根据本剧人物、金手指和前文实得的收益判断某种安排为什么适用。可以借用样稿的找事动机、期待的建立、亮优势或收场方式，也可以为本剧设计新事；桥段进入本剧，须接住本剧前因，并让下段的人物有事可做。新剧每个事件都要从用户设定、题材硬要求和前文结果中说得通。已有定稿的说话方式、用户手改稿和明确偏好优先。

读样稿时，为典型场面标明出处，包括相对技能目录的 Word 路径、集数、场次或场景，以及它适合哪种身份和交锋。可以一并记下动作触发、连续的一轮原话和对方随后的反应。例如议价段要保留谁让价、对方为何转身、哪句话把人叫回来。把样稿的原话和自己提炼的做法分清楚。把适合当前事件的几处交给写作，方便它回读原场。已有完整原场记录就直接用，不为全库建立索引，也对话里只给几个代表案例。
