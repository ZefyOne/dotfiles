# 集尾卡点

第1–79集先问观众正等着看哪一件事。把本集该办成的事演到应有的位置，再定停在哪个决定、动作或人的哪句话。每集规划记下本集变化、停笔位置、观众期待和下集最先接的行动。靠对白成立的卡点写出拟用末句。用户指定或确认了具体台词时，原句随规划交给写作。已确认的关键事件、停笔位置或原话需要实质调整，标出影响的集数，等用户确认。

## 首集觉醒

采用本剧默认开局时，同一集先演受辱，再让观众亲眼看见金手指首次生效。最后让主角震惊地用一句大白话直接喊出刚显现的实际功能，让观众知道他凭什么能翻身。第2集接着试用、收获。若用户给了不同的首集卡法，沿用用户版本。首集的觉醒有专门的写法，其余各集按下面的情境选择卡点。

## 普通集怎样留期待

| 现场已经发生的事 | 怎样停、下一集接什么 |
| --- | --- |
| 人物作出决定 | 收获已经拿到，主角决定拿去卖。下集接买家看到货、能卖多少。必要时可用极短独白。 |
| 关键结果即将揭晓 | 人物已作判断、点定验看的位置。停在即将验证的那一步，下集开场让观众看到结果。 |
| 交锋加了一层压力 | 对手在场上开出新条件，具体影响一笔生意或一项选择。下集接被逼作选择的人怎样回应。 |
| 一件事刚办完 | 收钱、分货或离开，结果使人物接下来有了一个新打算。让本段演足，再从这个决定开新事件。 |

一集里已经发现、解释过的东西，集尾不能再当新发现。能当场完成的验货、结账、赔付按因果兑现。跨集时要留给下一集一个具体期待，并让这一集已有实质进展。核对遮去末句后本场是否还在为同一件事蓄力。

## 两类常规震惊卡点

1. **打脸高潮。** 先让观众等主角凭已知优势反击，再让先前打压主角的人当面看到或确认这个足以推翻他判断的结果。末句直指主角的本事、成果、身份或功劳，只留第一反应。比如真品已获验证，反派说「这居然是真的青花瓷！」，本集到这里结束。反派只需认出成果，无须问它从哪来、多少钱捡到、为什么运气这么好。主角也不为反派的手段惊叹。下集接原现场，演反派持续的反应、被收拾、付代价和离场。
2. **主角首次发现值钱的新物。** 在集尾让主角刚刚发现或第一次认出它的真实价值。观众要能看懂这东西为何难得、值多少、值不值得他吃惊，然后才想看他怎样拿到它。分量不足或本集早先已经认出，改用接下来的行动或决定。

两种情况都核实谁在场、他原来怎样判断、刚看到什么足以震惊的证据。拟用末句有一个可指认的震惊点，台词短而直接。写作以人物、全角情绪括注和台词表现当场反应。赶海要让观众看见主角抓到了别人难得的货，鉴宝要看清主角的眼力使真品得到验证。把本剧的爽点留在主角身上。

## 阶段边界和全剧收尾

通用第8–11集的事件从第1集的具体羞辱起笔。第10集末亮出优势，停在首集反派亲眼见证后的震惊。第11集从实际第10集末场接反应与代价。专门的[打脸规划](face-slapping.md)同样适用于后续高潮。其他阶段的最后一集也可停在未完事件中，记下实际末句、现场人物、事物去向和待兑现事项。第2、11、31、51集分别从采用版本的实际末场承接。

第80集落实主角、长期反派和已设感情线的最终选择或处境，兑现重要承诺和伏笔。最后一句和可见结果共同收全剧。
