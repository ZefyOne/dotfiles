# 长线、循环与节奏

## 从本剧的终点倒推八十集

先依用户确认的线数构思。双线走赚钱主线与反派线，三线再加感情线。用户还没选时先确认。全剧开写前，先想清第80集观众能看见的结果。主角的本事最后给他的日子带来什么实在变化，长期反派怎样走到破产、生计难以维持，三线剧的感情最终落在哪个选择上。再把各段主要事件从开局顺到结尾，粗排各自的集数和重要人物的出场。越靠后的安排越留出调整余地。细化后文时从实际定稿出发。

- **赚钱主线**抓住反复想看的那一下。写清金手指的功能，以及主角用这项本事怎样占到别人占不到的优势。让观众看到判断、行动、收获、成交和钱的用处。每轮在收获、赚头、生活和选择上有所推进。赶海继续凭渔获赚钱，鉴宝继续靠捡漏赚钱。除非用户指定，开店经营、修东西接单和扩大事业都不能替代原本的赚钱方式。没有买卖的题材，以当场可见的成果兑现，例如医术见效。
- **反派线**从主角的成果、旧有关系或眼前利益生长。谁看到了成果、想占什么便宜或怕丢什么、为什么现在找来？动机可以很小。给主角一个值得观众等着看的反击。长期反派每次败走都记下已失和还剩的筹码，他下次拿什么找事要接得上这次损失。个人终局留到大结局，逐个演出破产和失去基本生活来源的后果。
- **感情线**只在已确认的三线剧里安排。先有共同经历，再有一方主动相信、靠近或作出选择，最后看这个变化怎样影响后续行动。赚钱与冲突仍要走得下去。

为本剧拟定能反复兑现的循环，沿用用户指定的环节。收获、变现、改善生活、反击可以交错，也可由一次交易承担两个作用。先串因果，再给各段分集。对外写清采用几条线、循环是什么、节奏依据是什么，沿用用户已经确认的安排。

## 把完整事件串起来

1. 写出上段留下的具体人、物、收益、承诺或决定，以及谁因为它采取了下一步。先用已出现的人物与条件，新人登场要有自己的事做。
2. 让主角亲自判断或行动，给出能在现场看到的收获或胜负。卖货要落实谁出价、谁收钱。拿到钱以后，改善生活可以是终于舍得吃一顿好的，家常戏也能让观众看到人物关系怎么变了。谁更急于成交，谁就会先开价、让步或挽留。
3. 参与交锋的各方怎样看对方、想从对方那里得到什么，怎样因此行动，按一段交往写一次，给用户看的规划中要能看见。独处段直接安排发现、行动、收获和当场反应。金手指的秘密可只让主角和观众知道，旁人看到成果即可服气，无须追问运作原理。人物称呼和判断以此时已经获得的信息为限。
4. 先收住当下的成交、得失或反应，再由其结果开下一件事。例如本集卖完货，买家离开，主角数钱决定改善伙食。下集买肉回家才遇到上门的反派。一段连续戏尽量集中在一两个主要场景。走路、等人、跨天等过程只保留能改变局面的部分。
5. 对照相邻两轮的阻碍、利益、主角选择、对手筹码和实际结果。抽掉上段，若下段仍能原样发生，补进这次结果造成的具体影响。互换两轮仍毫无影响，检查是否只换了货名或反派名。并行发展的支线分别因果成立即可。尚待兑现的事记下触发条件和回收位置。

## 先提题材节奏，空缺处再用默认走法

先按用户已定或已确认的安排，再用本题材设计逻辑与节奏表。默认排法由 AI 提给用户微调。节奏说明一个完整事件占几集、环节怎样合用一集，按整集或半集表达。题材文件覆盖的集段、顺序和节点优先于下表，具体事件从本剧设定和主角的能力构思。

| 集段 | 通用节奏表的补位走法 |
| --- | --- |
| 第1集 | 从正在发生的羞辱、背叛或夺利入戏。一两件重而不求回报的付出，接对方把这份好当成应得、又当面伤害主角的具体言行。给主角当场反应和离开的理由。末尾觉醒，按[首集卡点](hooks.md#首集觉醒)收住。 |
| 第2–3集 | 第2集让主角试用本事，演清发现、判断、取得第一份具体收获。第3集变现或交出能验证的成果。若有改善生活，让观众看见这笔钱解决了什么。 |
| 第4–5集 | 题材排法留出这段打脸时，第4集末亮优势，第5集接反应、代价、离场。可以是与首集无关的新反派，也可以让他以后再来。 |
| 第6–7集 | 主角再用本事取得新收获，为接下来的兑现备好筹码。参与的人物要对本次事件或后续关系有用。 |
| 第8–11集 | 让首集欺负主角的反派回场，拿原先的羞辱再压他。把售卖或题材上的成果兑现带入冲突。第10集末优势当场坐实，卡在反派第一句震惊。第11集接同一现场，演清反应、代价和离场。这是一段跨越交稿批次的戏。 |

## 用五个写作阶段细化同一部剧

第1集单列精排，第2–10集按第一集定稿校准，第11–30集接前十集定稿。接上用户指定的第1–30集正文，按连续集段排第31–80集、一次给用户看。再分第31–50、51–80集内部细排，后者衔接实际第50集末场。跨集段尚在进行的交易或冲突沿原走法演完，不在交稿边界硬收或另起。各阶段给用户看的内容和版本交接见[规划流程](../SKILL.md)。

后半部放缓，主要是同一段取得收获或反击的过程有更多篇幅。用户和题材均未指定的集段，用前十集常规段作基准。从11–30、31–50到51–80集，新开的收获赚钱段、打脸段可比上一阶段同类环节多约两集，按值得演的实际进展决定。每多用一集，写清新增哪项选择、障碍、成果、关系变化或兑现。七八集的打脸可[分段升级](face-slapping.md#长段怎样拆集)。临近结局，通常在51–80集可按连贯性调整快慢。第80集必须兑现全剧结局。

逐集细排时，用新正文约1030字（通常1000–1060字，含标点）的空间衡量戏够不够演。优先给关键判断、出手、反应和得失留篇幅。用户定下的短集沿用实际字数，后文直接接戏。
