# 赶海题材节奏

按[赶海剧情设计逻辑](../../references/剧情设计逻辑/赶海.md)规划。先定每段剧情的主要任务，再分配海上和岸上的篇幅。滩上或海上都写主角怎样找到、亲手抓到这批鱼虾，主要渔获到手就报估价和收入对比。岸上接实际渔获写验货、过秤、报价、付钱，也可承接生活变化和家长里短的冲突。已由用户指定或确认的安排优先。

- **出海超过3集必须分段。** 按整趟出海的集数判断，跨批出海也用同一份分段安排。规划时标出每小段的集数和实际收获。6集可拆成2＋2＋2，7集可拆成2＋2＋3，9集可拆成3＋3＋3。长出海的三次收获按[赶海剧情设计逻辑](../../references/剧情设计逻辑/赶海.md)递进，各小段占用的集数算在对应阶段的总集数内。
- **按实际收钱计赚钱段。** 同一趟的各次捕捞、上岸卖鱼和卖鱼现场的小打脸，实际收钱后合计为一段赚钱。单独排的打脸按[起因、发展、高潮、结果](../../references/templates.md#打脸段四项)写清，把反派付出的代价演出来。多集打脸通常在该段倒数第二集末卡反派一句震惊，最后一集接原现场兑现。
- **写作批次按实际末场交接。** 第30集和第50集都可以停在出海、卖鱼或打脸过程中，下一集接着写。剧情段到事件实际结束时才收完。

## 第1集、第2–10集与第11集承接

规划方先按下表提出前十集节奏供用户微调。第一集单独详排和定稿，依据定稿校正第2–10集。

| 集数 | 剧情任务 |
| --- | --- |
| 第1集 | 演足付出和受辱，集末觉醒金手指。主角亲见效果后，用一句惊喜或震惊的话说清能力。 |
| 第2集 | 主角用金手指赶海，抓到第一批鱼。末尾决定带鱼去卖。 |
| 第3集 | 写卖货、收钱和主角拿到钱时的反应。改善生活可随本集落地，也可在买家离开后收在「我也吃顿好的」，第4集开头用几句买完，再接反派上门。 |
| 第4–5集 | 反派因家长里短过来嘲讽。主角用前面打到的鱼，或卖鱼钱买回来的肉，当面让对方看走眼。 |
| 第6–7集 | 再写一趟赶海，抓到下一批要卖的鱼。 |
| 第8–9集 | 开始卖第6–7集抓来的鱼，把反派来找事和这笔买卖接在一起。 |
| 第10集 | 卖鱼过程推进到打脸的高潮。集末让第一集欺负过主角的反派亲眼看见主角的渔获，或看到买家当场确认收货，用他的一句震惊收住。 |
| 第11集 | 接第10集原现场，买家付钱，主角实际收款，演完反派的反应和代价。 |

## 第11–30集

第11集先收完前一段卖鱼和打脸。随后按**赶海收获、上岸卖鱼赚钱**交替排，每段约5集，按当轮的实际剧情调整。把买家收货、付款和由成交带出来的岸上戏写进卖鱼段。

本阶段以赶海衔接下一批。第30集可以停在这趟出海途中，第31集从同一现场接写，等捕捞结束再回岸上卖鱼。

## 第31–50集

常规按**两段赚钱接一段打脸**推进，每段约6–7集，按海上和岸上各有多少事值得演调整篇幅。跨到下一批的剧情按实际进度接着写。

1. **先接完第30集留下的那趟赶海。** 捕捞已结束就接上岸，现场没结束就先接完，再上岸卖鱼、收钱。这笔收款算本阶段的第一段赚钱，接着多写一段岸上发生的事。
2. **阶段中间新开一段约7–8集的出海。** 本阶段的新出海就排这一段，写主角亲手打到下一批好鱼。回岸上卖鱼、收钱后，算第二段赚钱。
3. **其余篇幅放在岸上。** 从前两笔买卖的鱼、钱或家长里短里接出一段打脸，收完它的结果再往下一轮走。

## 第51–80集

第51集从第50集实际写到的位置接起，先接完进行中的出海、卖鱼或打脸。后30集按各条线还需要兑现的事安排，可以只写一段赚钱。各段占几集按具体情节和第80集的收束需要确定。

- **主要出海段**可写约9–10集，分三次演出主角亲手打到的渔获越来越值钱。最后一次打上一条或一只本身就值几百万的海货。
- **短出海段**只在余下集数缺少可以推进结局的剧情时加，用约3–5集写抓鱼赚钱。出海部分超过3集照样分段。回来卖鱼收钱后，可以接一段打脸收尾。
- **其余篇幅在岸上。** 接住各趟打回来的鱼，写成交收钱、生活变化和打脸结果。第80集收完本剧已定的结局。主要反派和长期反派必须破产，惨到无法维持基本生活。把他具体失去什么、日子怎么过不下去了演出来。
