# 逐集逐场审正文

按播放顺序读本次指定的正文。先对照用户已定的剧情、节奏和卡点，再查本剧的[题材设计与节奏](../../drama-planning/SKILL.md#题材资料与规则优先级)，空缺处才用通用标准。以下检验都在原稿上试读。发现问题，记下集场、原句或动作、判断依据、建议改哪一拍和牵动的后文，交主控按问题分派。

## 一集做成了什么，一场为什么要留

1. 每集用一句话说清主要事件，指出结尾比开头改变了什么。逐场找人物为何此刻来、要办什么、怎样动手、得了什么结果。对手戏对照规划里双方怎样看待彼此、各想从对方那里得到什么，看谁先开口、谁肯让步、谁转身走。独处戏查主角的发现、行动、收获或决定。
2. 找到引起人物选择的那句话、动作或证据。开场应看懂人物关系、争什么、谁正受到什么伤害。主角从受委屈到拒绝、关系从决裂到松动，各自是被什么触动的？已醒悟又让步、反派受挫后又能使坏，分别查眼下的理由和手中剩余的条件。
3. 试抽掉一场、一个动作或一段重复交锋，顺读前后。若动机、选择、必要信息、情绪和后果都一样，指出可删处或可并入哪场。若删去后羞辱变轻、见证缺席、反击来得突然，就指出这场该留的那一下。相似段落并排查触发、争夺物、手段、主角选择、得失和卡点。若两轮只换货名、人名或金额，先建议在原桥段内调整选择、攻防或结果对下轮的影响。
4. 连读上段最后一场与下段第一场。上件事的收益或代价演到哪里？是谁据此作了下一步决定？卖货收钱后想改善伙食，足以接下集买肉。本场若连下一次买卖也挤进来了，指出应在哪个结果收住。第2、11、31、51集各接采用版本的实际末场。只拿到上半段时，核对已定接法，把实际开场和兑现列为待核验。节奏依据见[长线、循环与节奏](../../drama-planning/references/arc-and-pacing.md)。

## 主角的本事、看点与打脸

- 找到决定胜负的主角判断、选择或行动。搭档、孩子、权威可配合，双核心按已定分工看各自的功劳。孩子的话对准眼前的事，动物的动作和交流合乎其意图与设定。逐次核对金手指的首次显效、触发、对象、作用范围、条件、代价和知情者，查升级、受限及重要胜利是否接得上本剧已定的本事和爽点。
- 区分观众看到的机制和角色亲眼看到的成果。弟弟见过小虾，又见主角端出一筐大虾，他光是惊在大虾上，反应就成立。若他说破了变虾的秘密，向前找他能这样判断的见闻；没有依据时，建议把他的反应落回眼前这筐虾。只有追问会影响行动、试探或下一步选择时，才需要问来路。
- 跟主角走完题材实操。[赶海](../../drama-planning/references/剧情设计逻辑/赶海.md)及赶山看判断、出手、应变和到手的货；[鉴宝](../../drama-planning/references/剧情设计逻辑/鉴宝.md)看外行为什么误判、主角凭什么认出、怎么验证，分清估值和实收。关系戏看哪一次具体伤害逼人选择，这个选择又怎样改变两人。收获和温情回扣此前的真实难处，例如货卖成、收了钱，才付得出药费。找出已许的收获、惩罚或关系回应在哪场落地。
- 按[打脸剧情](../../drama-planning/references/face-slapping.md)把反派的断言和高潮的现场事实并排读。反派争什么、凭什么欺压？观众在哪一拍已经知道主角的优势，因哪句话更盼着看反击？七八集的长段按两三个阶段看小反击改变了什么，对手又动用了什么新筹码。多集高潮按已定集数，未定时通常看该段倒数第二集末。主角当面坐实优势，打压他的人亲眼看懂，停在第一句震惊。下集从原现场接反应、肉痛、实际损失和离场。小反派求饶的狼狈要接得上此前的嚣张；长期反派仍不服，下次出手只能用还在手里的筹码。

## 首集与前十集

先读本剧已定的开局和题材节奏。采用[前十集默认走法](../../drama-planning/references/arc-and-pacing.md#先提题材节奏空缺处再用默认走法)时，按下表审。每一集指出观众此刻最想看到哪一下，以及哪句台词或哪个行动让人生气、期待、解气或替主角高兴。收获、兑现、打脸要看实际结果和当事人的反应。

| 集段 | 连读时找什么 |
| --- | --- |
| 第1集 | 看主角此前哪一两件重而不求回报的付出，被对方当成应得；当场哪句话或哪个动作让主角决定离开。默认觉醒先演能力生效，再由主角惊呼实际功能。逐字核末句。连看末句前的几个动作，指出观众在哪一拍已经看懂能力；试剪后面又看、又摸或又试的一拍。若发现、人物反应和冲击力都照样成立，标为可剪；真正完成验证的那一步要留。用户另定首集卡法时从其安排。 |
| 第2–7集 | 第2集实际试用并取得首份收获；第3集查成交、所得或可验证的等效成果。题材留出第4–5集打脸时，连读亮优势、对方反应和付代价的场面。第6–7集查新收获和下一轮可用的筹码。 |
| 第8–11集 | 对照首集那句羞辱，看首集反派怎样拿旧事再压主角，又被哪件事实驳倒。第10集末的第一句震惊与第11集原现场的损失、离场连读。只审到第10集时，标明实际兑现待核。 |

## 场面、人物反应与台词

- **画面和场头。** 顺着 `▲` 看谁出手、对谁起作用、位置和危险方向怎样改变、谁看到后作了什么反应。抽象心理应找到可拍的动作、可听的反应或本剧允许的 OS。一段连续戏尽量留在一两个主要场景，每次切换要带来必要信息、行动或结果。对照[分场正文格式](../../drama-writing/references/scene-format.md)逐集查中文数字标题，逐场核对编号、时空、场景、人物四行及正文分段。时空只选 `日/内`、`日/外`、`夜/内`、`夜/外`，具体光线落在动作或字幕。
- **反应有没有接准。** 遮住全角情绪括号，连读上一拍和本人的第一句话。「你动什么手」得接得上推搡等动作。只有言语冒犯时，建议让人物直接回应那句话。亲近的人背叛可以先心寒，再以拒绝或离开表态。反派在得意、找补、求饶或嘴硬时，语气和行动应跟着他要争取或保住的东西变。查受辱或越界后的第一句、当众嘲讽、关键震惊和翻盘后的关键反应用 `人物（情绪或语气）：台词`，普通交代按需标。
- **先删整轮，再缩句。** 试拿掉一句或整轮问答，把前后的动作、台词接起来。事照样推进、选择和情绪力度都一样，就指出可整轮删的起止句；少了这句就看不懂拒绝或等不到该有的痛快，就留有效的那句。对余下的台词试删为交代信息硬搭的问句、寒暄、同义反复、动作已交代的解释。首集逐字过，第1–30集一个信息能用一句大白话说清就用一句，第31–80集可用两三句自然说开。交换同场两人的重点台词试读，复核称呼、年龄、身份、利害和知情依据。指出代作者讲道理、空放狠话、孩子长篇讲规则、人物回应听不到的 OS 等具体原句。见[台词、动作与人物反应](../../drama-writing/references/dialogue-and-performance.md)。

## 卡点与篇幅

- 第1–79集从末句向前找本集已发生的变化，再向后连读下集第一拍。普通集尾看观众具体等哪个决定、待揭结果或新压力的回应。已经揭过的发现又演一次、临时添事硬凑期待时，从现有进展中指出更合适的停笔位置。已确认原话或核心事件如需变动，标出会牵动的集数，交主控核对授权。第80集查主角、长期反派、已设感情线和伏笔各自的下落，以及末句如何与可见的结果一起收全剧。
- 首集默认觉醒按[首集专规](../../drama-planning/references/hooks.md#首集觉醒)。其余集选常规震惊卡点时，查说话人是打脸高潮中亲眼确认优势的反派，还是集尾首次认出有分量值钱物品的主角。遮去「（震惊）」和末句，用此前演出的事实核对人物原判断与现场的落差。末句只惊在一点上，一句短口语，说完即停。鉴宝戏再略去买价和差价试读，看看能否看清主角眼力、判断或出手的功劳；若开场已认出真品，结尾可接买下后去哪儿卖。见[集尾卡点](../../drama-planning/references/hooks.md)。
- 完整新集按[篇幅和排版](../../drama-writing/references/scene-format.md#篇幅和排版)统计实际正文，含标点，默认目标 1030 字。低于 1000 字指出规划中哪次选择、收获、交锋或反应写薄了；超过 1060 字指出哪轮交代或流程可压。修订稿逐集复计。片段按用户指定终点审，已有篇幅约定依其约定，锁定的定稿只报偏差。全剧合交时还要按同一口径核对正文总数 80000–85000 字。
