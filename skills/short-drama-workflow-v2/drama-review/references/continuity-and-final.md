# 连续性与全剧终检

本文件用于跨集、跨阶段的连续性核对，及全剧写齐后的全文核对。正常初审和复审结合[正文硬性审查](must-follow.md)和当前阶段规划。

## 阶段交界

按当前实际采用的前稿和规划核对交接，不使用尚未确认的后期大纲替代实际正文。

| 当前范围 | 核对接点 |
| --- | --- |
| 第1集 | 项目设定、第1集规划、开场处境、核心关系、能力或核心转折和实际末场。 |
| 第2—10集 | 第1集实际末场、前十集规划、人物状态、首轮收获、冲突、卡点和第10集实际末场。 |
| 第11—30集 | 前十集实际末场、11—30集当前规划、阶段事件、结果、反击和阶段收束。 |
| 第31—50集 | 前三十集实际末场、31—50集当前规划、主要转折、冲突升级和第50集实际末场。 |
| 第51—80集 | 前五十集实际末场、51—80集当前规划、剩余主线、反派后果、关系选择和第80集结局。 |

每个交界都要对读上一集末句、动作、在场人物、道具去向和已经发生的结果，以及下一集最先接上的一拍。交易、冲突或承诺跨阶段时，从起因读到实际兑现。缺少后文时，标为待核验。

## 连续性追踪

| 项目 | 核对内容 |
| --- | --- |
| 人物与知情 | 姓名、身份、称呼、关系、态度、进出场和消息来源。人物只能使用已经看见、听见或被告知的信息。 |
| 能力与道具 | 金手指首次显效、触发条件、范围、限制、知情范围，道具和证据从取得到交接、使用、损坏或消耗。 |
| 时空与动作 | 日期、期限、路程、上一场如何离开、下一场如何到场、人物站位和连续动作。 |
| 伤势与承诺 | 受伤、恢复、资格变化、人物承诺、到期时间和兑现位置。 |
| 钱与欠款 | 按重要人物分开追踪收支、余额与欠款。双穿故事还要分清交易在哪一界、用哪种钱。报价、应付和实付分开；转账、兑换按正文记去向。凡正文报余额，按同一人、同一币种的期初余额加实收减实付复算。缺本金或交易依据时标明缺口，勿补造金额。 |
| 货物与交易 | 按批追查货物来源、数量、持有人、带往哪一界、交货对象、剩余数量，以及何人已付、未付。跨段交易按上下集实际签收、付款和在场人的知情更新。 |
| 合稿版本 | 分开记录聊天修订版、实际生成的 Word 版及各自覆盖集数。以指定载体逐处核实修改，再查集号、场次、人物栏、旧名旧物和编辑备注。聊天已改、文件未更新时，指出文件仍保留的旧内容。 |

## 全剧终检

全剧写齐或用户要求全剧终检时，锁定最新指定正文版本，从第1集连续读到该剧最后一集。按本剧要求逐条核实，注明实际版本、载体、覆盖范围和缺失材料。只拿到末批时，先查收到的部分，全剧状态保留待核验。

- 顺着每条已确认主线查起因、行动、结果和后果。主角的核心能力、选择和资源是否真正解决最终矛盾。
- 查重要关系、承诺、伏笔和开局目标是否在正文中兑现。
- 查阶段交界、循环、收获、反派代价和结局是否有正文依据。
- 查长期反派的每轮损失和最终实际处境，不能只用一句话宣布结果。
- 修订稿重新阅读改处、交界和后续兑现位置，更新报告中的采用版本和待核验事项。

全剧终检只返回审查报告。Word 排版、字数统计、文件生成和交付由主控 skill 按其文档交付规则处理。
