# 短剧正文写作

把本阶段已经定下的事演出来。选谁先开口、用哪个动作逼人表态、在哪个字上收住，都是写作的事。用户定下的人物关系、剧情顺序、知情时点、卡点和原话先锁好。

## 开写前拿到什么

1. 从[主控](../SKILL.md)接本次集场范围、已确认的规划、人物关系和每段对手戏的「人物心理」、题材硬要求、用户最新修改。续写要读指定定稿的实际末场；返修要读待改原文及具体意见。规划已给出的信息直接使用。缺少会改变写法的关键事实，只把缺项退给主控；用户已给出具体逐集安排或明确指定的局部改法，可以直接作为本次依据。
2. 逐段认清谁把谁当成什么人、谁要对方做什么、各自眼下知道什么、事情演到哪里必须停。区分用户锁定的原话和规划拟的台词。锁定的字词、标点照录；拟句可按角色口气改，保留已定事实、说话人、震惊对象和停笔位置。
3. 优先读本剧用户亲手改过或已定稿的相近场次。对手戏取规划交接的同题材对白出处，回到[题材样稿目录](../drama-planning/assets)读这一次从起因到回应的完整交锋；交接里已有完整来回和动作就直接用。样稿只借说话和反应的写法。遇到没有对应原场的戏，凭本剧已定关系与事实写，不编来源。

## 按场落笔

- **每次写或改对白，先读[台词与人物反应](references/dialogue-and-performance.md)。** 用红果短剧里一听就懂的大白话。先问这句话交代了哪件事，或者让观众在这一刻更生气、更期待、更解气。两头都落空，整句删。一个信息一句能说清，就别让两个人来回问答。
- **新写或重排场次，读[分场正文格式](references/scene-format.md)。** 一段戏从该发生的那一刻切入。把人物态度写进称呼、动作、抢话和选择。让观众亲眼看见关键决定和实际结果。一个事件演到本集该收的位置，再用它的结果带出下一件事。
- **遇到题材关键戏，落实该题材的硬要求。** 按本剧选读对应的[赶海规则](../drama-planning/references/剧情设计逻辑/赶海.md)、[鉴宝规则](../drama-planning/references/剧情设计逻辑/鉴宝.md)或规划交来的同题材规则。演出主角怎样凭本事拿到好东西。抓到时的估价、买家肯出的价、最终收到的钱要分清。旁人看得见成果就能服气；秘密如何得手、后来才揭开的身份，只让此刻知情的人说。
- **写到集尾，对照[卡点](../drama-planning/references/hooks.md)；写打脸段，再对照[打脸的四步](../drama-planning/references/face-slapping.md)。** 前面压观众正在等主角反击的那个点，高潮亮出恰能反击的优势。规划定在反派震惊处，就在他的第一句反应停笔；下集接原现场，再演他的狼狈、损失和离场。日常收获、决定或待验的结果，按眼前进展留期待。第80集把已定结局演完。

## 五个阶段怎么用力

| 本次写作 | 正文重点 |
| --- | --- |
| 第1集 | 单独打磨。默认开局把主角不求回报的重大付出说具体，让反派当面把这份好当成应得，再让主角当场作出选择。把金手指第一次生效演给观众看，最后让主角用一句大白话惊呼它的作用。逐字读，尤其检查开场铺垫、重复控诉、觉醒后的二次解释。 |
| 第2–10集 | 接用户指定的首集定稿。逐句查信息或情绪的作用，删闲人、寒暄、重复演示。第10集按确认的高潮卡点停住；第11集要演的代价留在原处。 |
| 第11–30集 | 接前十集定稿的实际末场。一个信息一句能讲完，就在这一句讲完。收获、成交、冲突各有新进展；取消过的订单、约定、称呼就从依赖它们的新稿中一并清掉。 |
| 第31–50集 | 接前三十集定稿和已确认的后五十集分段大纲，按规划内部细化的分集来写。一个信息可用两三句自然带出，每次接话要有用。长事件每一小段给出实际变化。 |
| 第51–80集 | 接前五十集实际稿与本批内部分集，安排已定的回报、代价、关系和结局。同一事件可跨第50集。让观众看到最终谁得到什么、谁失去什么。 |

## 初稿完成后逐场精修

每批初稿写完，从本批首集到末集顺着剧情逐场读，在正文里直接改。单独精修已有稿时，用用户指定的版本，在指定的集、场或原句内动笔。以已确认的主线、人物关系、事件结果、卡点和锁定原话为准。

1. **只留跟主线有关的戏。** 先试着拿掉整轮闲聊、日常过场或多余细节，再接着读。人物为什么翻脸、做了什么决定、下一场为什么发生，观众照样能懂，冲突也一样有力，就删掉。删了会让拒绝来得突然、打脸少了依据，就留下起作用的那句或那个动作。
2. **让演员说得顺，观众听一遍就懂。** 连着上一句台词和上一个动作念。把绕口的话拆短，把含糊的「他」「那件事」换成听得明白的人或事。让最有理由开口的人接话，接住刚才的质问、条件或动作，让观众听出他在跟谁说、为什么现在说。人物嘴里的行话、专业术语换成平常人会说的话。
3. **把事情演明白。** 遇到生僻物件，在剧情允许处换成观众熟悉、能起同样作用的东西。已定的关键物件，用常见叫法和看得见的动作演清它有什么用。把抽象的说理落到眼前具体的事上。顺着角色当时知道什么、手里有什么，核对他做得到这件事、作这个选择有来由。改过的道具、动作和决定要接得上前后场与下集。

## 自查、返修和送审

1. 逐集连读实际稿。从上一集末场读入本集首场，核对称呼与态度、在场人、消息何时传到、钱物去向及下集接法。遮住情绪括号还能听出人物态度；遮住震惊末句，前文也要足以撑住反应。整轮删掉仍一样有力的对白就删。完整集按分场格式实数字数；局部试写只查指定范围。
2. 返修只改用户或主控授权的集场、段落或原句。用户说「只改这一句」，用原稿替换这一句并比对前后原文。用户手改定稿逐字接用，错误或字数偏差只报位置。前因撤销会波及别场时，指出依赖位置；属于本次授权的新稿一并修好。需要变更已定的关键事件、人物知情、节奏或末句，交主控回规划确认。
3. 把**逐场精修并自查后的实际正文**连同集场范围、依据的定稿和规划版本、实际结尾与待接事项交主控，状态写「待审」；返修稿附已改位置和受影响的上下场，写「待复审」。状态和说明放在正文外，交付按[项目约定](../references/delivery.md)。主控组织审稿，只在实际核过对应版本后记录通过。
