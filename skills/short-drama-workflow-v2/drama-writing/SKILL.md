# 短剧正文写作

把当前阶段已经确认的剧情落成可拍、可演、可读的分场正文。正文写作负责场面、动作、对白、人物反应和集尾停笔，不重新设计剧情主线。

## 一、读取要求和接收交接

每次写作先读取[必须遵守](references/must-follow.md)，再根据任务读取[建议与参考](references/creative-guidance.md)。硬性边界必须执行，建议用于改善台词、人物反应、节奏、场面和语言，可以结合当前剧情取舍。

用户本次明确要求、用户已经确认的设定和主控锁定的版本，优先于两个参考文件中的内容。

完整流程只接收主控交来的已确认规划和版本事实。主控交接至少包括：

- 当前批次和集数范围
- 本次采用的前稿版本、实际末场及已确认的会话修订。用户在会话中改过的内容与现有 Word 有出入时，注明差异，按最新确认的文字续写
- 当前阶段已确认的剧情段、段末结果和指定集数的卡点。用户给了逐集规划时照用
- 人物目标、当前状态、知情范围和行动承接
- 已确认的人物关系、称呼、金手指边界、道具、金额和原话
- 尚未兑现的事件、本剧历次确认且仍有效的要求，以及本轮新增、替换或取消的要求

收到按“第几到第几集”写的规划后，在写作时把每段分到各集，先定本集推进、停笔位置和下集起手。保留锁定的重点集、卡点和原话，不要求主编再补一份逐集表。

规划没有写出每段戏的独立心理说明时，依据人物目标、立场、知情范围、眼前利益和事件结果来写人物反应，不把“人物心理”当成规划必须单独提供的字段。

缺少会改变剧情因果、人物知情、场景承接或集尾位置的事实时，退回主控，由主控决定是否让 `drama-planning` 修规划。不得自行改动核心事件、人物关系、结局或锁定卡点。用户单独调用本 skill 时，依据用户提供的规划、前稿和修改要求工作，并确认当前稿件处于初稿、返修、主编意见核对或精修状态。

## 二、五个完整批次

完整项目默认按以下五个批次交稿。长批次在每个剧情段末做一次内部回查，再接下一段，整批写完后一次交付。

| 批次 | 写作依据 | 写作重点 |
| --- | --- | --- |
| 第1集 | 已确认的项目设定和第1集规划 | 打磨开局受挫、核心关系、第一轮冲突、能力或核心转折和集尾期待。 |
| 第2—10集 | 第1集已锁定正文和第2—10集规划 | 承接首集事实，推进第一轮主线、反派线、爽点和第10集卡点。 |
| 第11—30集 | 前十集已锁定正文和第11—30集规划 | 推进本阶段的收获、冲突、反击和阶段结果。 |
| 第31—50集 | 前三十集实际定稿和第31—50集规划 | 推进中后段主要转折、冲突升级和第50集收束，不依赖后五十集详细大纲。 |
| 第51—80集 | 前五十集已锁定正文和第51—80集规划 | 完成剩余主线、反派代价、人物关系选择和第80集结局。 |

## 三、正文工作闭环

### 1. 初稿

按已确认规划和[必须遵守](references/must-follow.md)完成本批正文，先做格式、漏写、明显断句、硬性要求和字数的基础自查，完成后标为“待审”，交 `drama-review` 审查。

### 2. 审稿返修

根据审稿意见，只修改获得授权的集、场、段落或原句，并连读受影响的上下文。

- 剧情前因、事件顺序、人物知情、主线方向、卡点位置和后续承接问题，交回主控，由主控决定是否退 `drama-planning` 修规划。
- 台词、动作、人物反应、场面衔接、格式、字数和表达问题，直接在正文中修正。

返修稿标为“待复审”。不得借返修机会重写整批正文或改变未被授权的剧情骨架。复审通过后，进入主编意见处理或最终语言精修。

### 3. 主编意见返修

主控把主编提出的原话完整传给 writing，不代替主编整理、改写或重新解释。writing 按原话修改，修改后交 `drama-review` 对照原话检查是否真正落实。

主编意见最多进行两轮“审核—修改”往返。第一次检查发现问题后修改一次，第二次检查仍发现问题后再修改一次。第三次检查仍未改对时停止自动返修，由 `drama-review` 写明剩余问题、具体集场和不合格原因，主控把最后版本和说明交给主编，不进入精修。

主编意见审核通过后，进入最终语言精修。

### 4. 最终语言精修

只有初稿经复审通过或主编意见审核通过，且没有影响通过的必修问题后，才进行最终语言精修。精修从本批第一集连读到最后一集，依据[必须遵守](references/must-follow.md)中的精修合同处理台词、语境、口语化、重复、冗余和字数，不重新规划剧情。

精修完成后，核对字数、场景、卡点、连续性和核心事件，修回精修造成的实质变化。本批精修完成后交回主控。最后一批完成时，由主控汇齐各批采用版本，进入全剧正文核对。

## 四、执行顺序

1. 读取本批规划、前稿实际末场和用户最新要求。
2. 读取[必须遵守](references/must-follow.md)。
3. 按任务读取[建议与参考](references/creative-guidance.md)、题材建议和用户指定样稿。样稿只学习表达方式，不照搬人物、物件和事件。
4. 落笔前确认每场戏的目标、人物立场、知情范围、在场人物、手里持有的东西、动作结果和下一个承接点。完成后按当前状态返回稿件和必要说明。

## 五、交接状态

- 初稿完成后返回“待审”，附实际集场范围、依据版本、实际结尾和待审事项。
- 返修完成后返回“待复审”，附修改位置、对应旧问题和受影响的上下场。
- 最终语言精修完成后返回“已精修”，附本批范围、采用版本、实际末场、钱物和未兑现事项的变化，由主控交主编。上述交接信息供内部续写和核对，交给主编的正文文件默认只放所要集数的分场正文；主编指定直接发会话时，只贴所要正文。
- 主编意见第三次检查仍未通过时返回“待主编判断”，附最后版本、剩余问题和具体集场。
