# 台词、动作与人物反应

## 先听准本剧人物的口气

读用户指定的本剧定稿，尤其留意用户手改过的一来一回，沿用人物的称呼、措辞和说话分寸。再从规划给的同题材场次里，挑年代、关系、处境与眼前冲突最接近的一段。沿着开口前的动作，读完双方的话和对方听完后的反应。学清楚哪句话逼人松口、哪一下让人翻脸。落笔时换成本剧人物真正要争的事，用他们自己的话说，不套样句。

## 先删整轮，再修每一句

红果短剧用直白口语，先让观众听懂发生了什么、谁要做什么。每句至少起一个作用：推动眼前的事，或让观众更心疼、更生气、更期待、更解气。先抽掉一整轮寒暄、追问或争辩，连起来读前后。事情照样发生，情绪力度也一样，就整轮删。少了一句，后面的拒绝就没来由，或主角翻盘时少了痛快，就留下起作用的那句。

| 集段 | 怎样下笔 |
| --- | --- |
| 第1集 | 逐字过。以受辱开局为例，谁先逼人、主角曾替他做过什么、对方怎样回报、主角此刻怎么选，让观众听一遍就懂。压掉解释关系的铺垫、同义反复和只为接话的语气词，留下能让羞辱、心寒或反击更有分量的字。按本剧已定的开局和末句收。 |
| 第1–30集（含首集） | 一个信息一句大白话能说清，就由最有理由开口的人直接说清。省去一人发问、一人回答、旁人再确认的拆法。要留问答，就让回答影响对方的决定或把情绪往前推。 |
| 第31–80集 | 同一件事可用两三句自然说开。逐句看各自的作用，例如买家先压价，卖家听完收货要走，买家才肯加钱。删掉换个说法重报一次的条件。 |

需要交代身份或条件时，先试着删掉专门为它搭的问句。请客的人见对方摸钱包，自己就有理由开口；急着抢货的买家也可以主动亮身份、开价。真在试探立场、问完会改变决定的问句可以留。

## 把态度演给对方看

- 读这段规划的「人物心理」，想清每个人此刻怎么看眼前这个人，想从他手里拿到或保住什么。把态度写进可拍的动作、选择和口语。亲人翻脸时，主角可以愣一下，随后放下替他干的活，当面拒绝。动作已让人看懂的用意，省去解释。
- 人物只按亲眼见到、亲耳听到及据此能推到的事实开口。初见可以按身份招呼。要用 OS，就写角色这会儿能想到、足以影响下一步的念头。旁人听不到 OS，也不能凭只给观众看的特效说破秘密。
- 让每次接话都接住上一句或上一个动作。反派想夺哪笔钱，就当面拦谁收钱。主角回击也对准这次越界，能挡就挡、该拒就拒。对方只在嘴上羞辱时，主角直接截住那句话。抢话、改口、沉默都要看得出是什么逼出来的。
- 谁急着帮人、买货或攀交，谁先行动。请人吃饭，把热饭递过去就能见出好心；买家怕好货被人抢，就抢先出价。让称呼、谢意和让价跟着这两人的关系走。交换两人的重点台词，谁都能说的，按各自争的那样东西重写。念一遍，剪掉客套的报家门、绕弯抖机灵的反问和替观众总结的道理。
- 主角受辱或遭越界后的第一句、反派当众嘲讽、高潮或集尾的震惊，以及翻盘后找补、求饶或嘴硬的关键台词，按 `人物（情绪或语气）：台词` 写，普通交代按需标。遮住全角括号，连读触发它的动作和人物的第一句话，仍应听得出他冲谁说、为何动气或改口。

## 按已定卡点停笔

普通集演足本集的变化，顺着已经得到的结果，停在下一步决定、行动或逼人回应的新条件上。下集开头接观众正在等的那件事。写主角首次认出值钱的新物时，先给观众足够依据，再让主角惊在它的价值上。首集按已定开局处理，采用默认觉醒时，先让能力生效，再让主角用一句口语喊出刚显现的实际功能。

多集打脸的高潮先演清主角亲手做成了什么、拿出了什么，或凭什么挣得眼下的身份。权威可以验实，在场的人能认出功劳归谁。让先前施压的反派亲眼见证，第一句震惊直接说中推翻他原判断的那项成果，说完即停。下一集从原现场接他想怎么挽回、实际失去了什么。连读集尾和下集第一拍，核对本剧已定的停笔位置和末句。
